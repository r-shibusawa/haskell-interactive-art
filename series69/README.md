# シリーズ69：数理論理学 ─ Haskell コード集

「正しい推論」を記号と規則だけで扱い、論理そのものの力と限界を調べる ― **数理論理学**を自分で動かして確かめるコード集です。真理値表と標準形、自然演繹の証明チェッカー、導出原理から始めて、量化子と有限モデル、単一化と論理プログラミング（Prolog）、意味のタブロー、ペアノ算術と数学的帰納法、ラムダ計算、カリー-ハワード対応、ゲーデル数、対角線論法と不完全性定理、様相論理とクリプキモデル、正直者とうそつきのパズル、そして音とカメラまで、どれも**ライブラリを使わずに本当に計算した**シミュレーションです。p5.js 版と同じアルゴリズム（ASCII の別名つきの再帰下降の論理式パーサ、外側・左からの 1 か所ずつの書きかえによる CNF / DNF、フィッチ式の自然演繹のチェッカー、幅優先の飽和による導出原理、有限モデルでの一階の式の評価、出現検査つきのロビンソンの単一化と深さ優先の SLD 導出、α 規則優先のタブロー、パターン照合によるペアノ算術の書きかえ、変数の捕獲をさける β 簡約、単一化による型推論と直観主義の証明探索、ゲーデル数と素因数による復号、クリプキモデルでの □ ◇ の評価、総当たり）を Haskell（gloss）で書き直しています。上限（手数・深さ・ノードの数）も p5.js 版と同じで、種つきの乱数も同じ列を同じ順に引くので、画面に出る式や数は p5.js 版と同じになります。ゲーデル数は BigInt の代わりに Haskell の `Integer` で計算します。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series69/

## 使い方

```
cabal run s69-00
```

番号を変えると別のスケッチが動きます（`s69-01`、`s69-15` など）。どのスケッチも一番下に「論理の道具」（論理式の構文解析・文字列化・真理値表、CNF / DNF の書きかえ、木の描き方、ラムダ計算の簡約、種つきの乱数、自己テストなど）が入っています。

**論理式の書き方（画面の表示も入力も ASCII）**：gloss のフォントは日本語も論理の記号も出せないので、記号はすべて次の ASCII で表示し、同じ書き方で入力します（p5.js 版の別名 `!` `^` `>` `=` も使えます）。

| 記号 | ASCII | 記号 | ASCII |
|---|---|---|---|
| ¬ | `~` | ⊤（真） | `T` または `1` |
| ∧ | `&` | ⊥（偽） | `_\|_` または `0` |
| ∨ | `\|` | □ ◇（12 だけ） | `[]` `<>` |
| → | `->` | ∀ ∃ | `A` `E`（例：`Ax Ey R(x,y)`） |
| ↔ | `<->` | λ | `\`（例：`\x.x`） |
| ⊢ ⊨ | `\|-` `\|=` | × | `*` |

変数は小文字 1 字（p q r …、p1 のように数字をつけてもよい）。強さの順は `~` ＞ `&` ＞ `|` ＞ `->` ＞ `<->` で、`->` は右から（`p->q->r` = `p->(q->r)`）。ラムダ式（08・09）は `\` が λ、数字がチャーチ数、大文字が名前つきの式（PLUS TIMES TRUE K S など）。`T` と `_|_` は Haskell 版で足した書き方で、p5.js 版の `⊤` `⊥` にあたります（p5.js 版の記号の文字のままでも読めます）。

文字を入力するスケッチ：00・01・06・08・09・10 は文字キーがいつも入力で、操作は ↑↓ ← → Enter Tab Backspace だけ。14・15 は **Tab で編集モード**に切りかえてから入力します（編集中は文字キーがすべて入力になり、ほかの操作キーは効きません。Enter か Tab で終わる）。まちがった式を打っても赤い説明が出るだけで、前の正しい式のまま動きます。**全部消す**のは Shift + Backspace です（p5.js 版の Esc。gloss では Esc でウィンドウが閉じます）。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量は 0.2 以下）。📷 カメラ（15）はカメラがなくても領域のクリックで動きます（C で切りかえ）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や記号を出せないので、説明・お手本の名前・規則の名前・パズルの言葉は短い英語で、記号は上の表の ASCII で書きます。そのほかの記号：✓ ✗ は `OK` `x`、空節 □ は `[]`、タブローの閉じた枝・開いた枝・打ち切りは `x` `o` `...`、05 の木の印 □ ✗ … は `[]` `x` `...`、↦ は `->`、s⁵(0) は `s^5(0)`、11 のマスの 止 ∞ ⊢ ・ は `H` `oo` `|-` `.`、φ ψ は `phi` `psi`、≠ は `!=`、13 の 正 う は `K`（knight）`L`（liar）、04 の真偽は `T` `F`、02 の規則は `&I` `&E` `|I` `|E` `->I` `->E` `~I` `~E` `_|_E` `~~E` `RAA`。文字は 14 px より小さくしないので（p5.js 版は所により 8〜13 px）、長い式や説明は「...」で切ったり行を分けたりしています。03 の導出の木はラベルが重なるときは節の番号（C12 など）で、06 の大きな木は丸が少し重なります。パネルの角は丸くありません。
- **自己テスト**：p5.js 版と同じ項目を同じ名前で照合します（全部で 123 項目：00 から順に 10・8・9・7・7・9・6・8・9・9・8・5・8・7・7・6）。結果は起動時に端末に出し、画面の右下にも `Self-test OK 10 / 10` のように合格数を出します（テストモードでは失敗した項目とまとめの 1 行だけ）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、1 本の列を同じ順に引くので、自己テストのでたらめな式や、03・04・13 の R で作るでたらめな問題・世界は p5.js 版と同じになります。
- **キー**：gloss ではスペース・Enter・Backspace・Tab・矢印は特別なキーとして届くので、入力欄では文字に直して扱います（Mac の delete キーも Backspace）。Esc はウィンドウを閉じてしまうので、「全部消す」は **Shift + Backspace** です。15 の Esc（式を変えずに編集をやめる）にあたるキーはありません（Enter か Tab で終わります）。p5.js 版の Delete キー（全部消す）は、ここでは 1 文字消すだけです。
- **08 ラムダ計算**：黄色にするのは次に簡約する場所 1 か所だけです（p5.js 版は同じオブジェクトを指す部分を探すので、置きかえで共有された同じ形の部分も黄色になることがあります）。自動実行は skStep で 4 フレームに 1 歩進めます。
- **01・03・12**：重い計算（03 の総当たりの答え、12 の全部の付値での公理の判定など）は、問題や世界が変わったときだけ計算し直します。03 の自動の探索は p5.js 版と同じく 1 フレームに 600 組ずつ進めます。
- **14 真理値表のシーケンサー**：Web Audio の代わりに Art.Sound の `playTone` を使います。雑音や音の高さが下がる音は作れないので、キックは 60 Hz の正弦波（0.25 秒）、スネアは 190 Hz のノコギリ波（0.14 秒）、ハイハットは 6000 Hz の短い矩形波で近づけます（ベースとベルは同じ高さと波形。音量はどれも p5.js 版の音量 × 0.12）。拍は先読みせず、経過時間 `envTime` で数えます。同時に鳴る音は 8 音までです。
- **15 カメラで論理**：カメラは Art.Device（ffmpeg 経由、64 × 48、左右反転）で読みます。カメラがないときや C で切ったときは領域のクリックで切りかえます。`S` の保存は PNG ではなく SVG です。
