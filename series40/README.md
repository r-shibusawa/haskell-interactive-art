# シリーズ40：微分幾何学 ─ Haskell コード集

「曲がり方」を数で測る。平面曲線の曲率と接触円から始めて、空間曲線のフレネ標構、曲面の第一・第二基本形式とガウス曲率、測地線・平行移動・ガウス＝ボネの定理、極小曲面と曲率流、擬球の負曲率の世界までを、自分の手で動かして体験するコード集です。p5.js 版と同じ計算を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series40/

## 使い方

```
cabal run s40-00
```

番号を変えると別のスケッチが動きます（`s40-01`、`s40-15` など）。3D のスケッチはドラッグで視点が回ります。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。κ は `k`、τ は `tau`、φ は `phi` と書きます。パネルの角は丸くありません。
- **3D の描き方**：WebGL の深度バッファの代わりに、面と線を奥行きで並べて奥から描きます（画家のアルゴリズム）。色は面ごとに 1 色で、頂点の間のなめらかな補間はありません。面が交差する所や、面に沿う線の前後は近似です。
- **光**：環境光 1 つと白い平行光 2 つで陰影をつけています。p5.js 版の光は HSB モードの数値の解釈で少し色がつきますが、こちらは白です。
- **画面の大きさ**：起動時は 1280×800 です。3D のカメラの距離は高さ 800 の値に固定しています。
- **06 測地線**：積分は同じですが、描くときは 1 本 200 線分までに間引きます（長くすると折れ線が少し粗くなります）。
- **13 曲率を聴く**：鳴らしっぱなしの音の代わりに、0.2 秒ごとに短い音を鳴らします（`notePeriod` で変更可）。左曲がりは三角波、右曲がりは 1 オクターブ下のサイン波を鳴らし、もう片方の小さな音は省いています。発音までに少し遅れがあります。
- **14 フレネ・ブラシ**：紙に焼きつけるのではなく、描いた図形を新しい順に 7000 個まで覚えて毎フレーム描き直します。超えると古いものから消えます（`maxInk`）。`S` の保存は PNG ではなく SVG です。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。ffmpeg やカメラが無いときは p5.js 版と同じノイズ地形になります。
