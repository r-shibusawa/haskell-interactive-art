# シリーズ45：機械工学 ─ Haskell コード集

機械を「動かす・支える・回す・熱を仕事に変える」しくみとして組み立てる。リンク・カム・歯車の機構、応力・はり・座屈の材料力学、共振と危険速度の機械力学、熱機関までを 2D の図と式で体験するコード集です。p5.js 版と同じ計算（ループ閉じ込みの式、インボリュート歯形、RK4 など）を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series45/

## 使い方

```
cabal run s45-00
```

番号を変えると別のスケッチが動きます（`s45-01`、`s45-15` など）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。文字は 14 より小さくしません。記号は ASCII で書きます（θ は `t`、α は `a`、λ は `lambda`、² は `^2`、≤ は `<=`、° は `deg`）。
- **凹んだ形の塗り**：gloss の `Polygon` は凸の形しか正しく塗れません。形の計算（インボリュート歯形、カムの輪郭、p–V 線図など）は p5.js 版と同じで、塗り方だけ分けています。02・03 のカムと歯車は中心からの扇を凸の部分ごとに、04・05・13・15 の歯車は歯底の円板と歯 1 枚ずつの多角形に分けて塗ります（05 の内歯車は背景色の歯車の形を重ねてくりぬきます）。06 のくびれた試験片は細い台形 40 枚、07 のせん断力図・曲げモーメント図は細い台形、12 の p–V 線図の面積は横に細く切って塗ります。
- **06 応力–ひずみ線図**：たどった線は p5.js 版と同じく最大 4000 点まで覚えますが、1500 点を超えたら間引いて描きます。
- **08・09・10・11 の文字の配置**：数値の欄やラベルは、図と重ならないよう行を分けたり位置を少しずらしたりしています（08・11 の数値の欄は 5 行、09 の柱の下のラベルは 1 行ずつ、10 の「absorber」はおもりの右横）。
- **13 機械の音**：Web Audio の連続音の代わりに、0.3 秒の音を 0.25 秒ごとに鳴らします（のこぎり波の主音＋矩形波の 2 倍音）。偏心・失火の「音量のゆれ（AM 変調）」は、同じ意味の側帯波（主音 ± 遅い周期）を一緒に鳴らして表します。鳴らす音にはローパスフィルターがかからず、音量はブラウザの圧縮器の代わりに p5.js の 2.5 倍（`playGain`）です。スペクトルは AnalyserNode の代わりに、同じ信号（のこぎり波＋矩形波 → 2 次ローパス → 音量 → AM）をプログラムの中で作り、Blackman 窓・FFT・なめらかさ 0.6・−100〜−30 dB の同じ手順で求めます（22050 Hz × 4096 標本。窓の長さとビンの幅は p5.js 版と同じ）。音名は英語表記（C4 など）です。
- **14 リンク機構ブラシ**：紙に焼きつけるのではなく、紙の座標で線を 6000 本まで覚えて毎フレーム回して描き直します。超えると古いものから消えます（`maxInk`）。線は細い線で描きます。`S` の保存は PNG ではなく SVG です。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。カメラが無いときは p5.js 版と同じく、マウスの速さで回します。
