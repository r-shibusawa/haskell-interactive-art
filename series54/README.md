# シリーズ54：電磁気学 ─ Haskell コード集

目に見えない電場と磁場を、物理の式から**本当に計算して**描き、動かすコード集です。クーロンの法則・電場と電位・ガウスの法則・導体とコンデンサ（静電気）から、キルヒホッフの法則・RC 回路・RLC の共振（回路）、電流のつくる磁場・ローレンツ力・電磁誘導・モーターと発電機（磁気）、マクスウェル方程式を解く FDTD・アンテナからの電波・電磁波のスペクトル（電磁波）まで。p5.js 版と同じ計算（重ね合わせ、RK4 の電気力線、マーチング・スクエア、ラプラス・ポアソン方程式の SOR 法、ガウスの消去法、ビオ・サバールの式、ボリス法、∮A·dl、FDTD とムーアの吸収境界、ヘルツの双極子の解析解）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）、格子は unboxed のベクトルで行っています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series54/

## 使い方

```
cabal run s54-00
```

番号を変えると別のスケッチが動きます（`s54-01`、`s54-15` など）。どのスケッチも一番下に「電磁気の道具」（力と場の計算、矢印やグラフを描く道具、自己テストなど）が入っています。画面の左下の `Self-test OK n / n` は、起動時に計算を式どおりの値と照合した結果です（端末にも出ます）。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（ヘッドホンは特に注意）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です（μC は `uC`、Ω は `Ohm`、τ は `tau`、ε0 は `eps0`、×10⁻⁵ は `e-5`）。長い説明は 2〜4 行に分け、表や説明文の位置を少し変えています（01・02 の説明の黒い枠は少し広く、11 の格子は上の説明のぶん少し下、13 の身近な例は 7 段）。p5.js 版で 11〜13 の小さな文字は 14 にしています。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差で照合します（全部で 108 項目）。結果は端末に出し、画面左下にも `Self-test OK 7 / 7` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけ）。
- **点線**：`setLineDash` が無いので、短い線分を並べて描きます。
- **ピクセル画像**：色の地図（01 の電位、03・15 の電位、07 の |B|、11 の電場、12 の背景）は拡大するときにぼかさないので、p5.js 版より格子が見えます。
- **01 電場と電位・02 ガウスの法則**：p5.js 版の `dirty` と同じく、色の地図・等電位線・電気力線（01）と電束の積分（02）は、何かが変わったときだけ計算し直します。
- **03 導体とコンデンサ**：格子は p5.js 版と同じ 160 × 100、SOR（ω = 1.9、1 フレーム 40 回）も同じ順番です。細い矢印は 1 本の折れ線として描きます（見た目は同じ）。
- **07 電流のつくる磁場**：格子は同じ 129 × 81 ですが、1 フレームで全部計算すると約 100 ms かかるので、キーを押したあとは数フレーム〜約 20 フレーム（20 巻きのソレノイド）に分けて計算し、できあがったら背景と磁力線が新しくなります（それまでは前の絵のまま）。起動時は一度に計算します。|B| の背景は 10 ピクセルのます目です。
- **08 ローレンツ力**：質量分析器のイオンは `Math.random` の代わりに `randomRIO` で選びます。E×B ドリフトの「測った平均の速さ」は `performance.now()` の代わりに `envTime` で測ります。モード 2 の「B は上向き」の文字は情報と重ならないよう下に置いています。
- **11 FDTD**：格子は同じ 200 × 125、1 フレーム 3 ステップで、同じ更新の順番とムーアの吸収境界です。アンテナ（連続波）は最初から ON で、R でも ON にもどります（p5.js 版と同じ）。
- **12 アンテナからの電波**：等電位線のます目（6 ピクセル）と交わり方は同じですが、ます目ごとの短い線分のままだと図形の数が多すぎるので、線分をつないで 1 本ずつの折れ線にして描きます（形は同じ）。
- **14 テルミン風**：Web Audio の連続した音の代わりに、Art.Sound の `playTone`（正弦波）で差の周波数 Δf の短い音（0.18 秒）を 0.15 秒ごとにくり返し鳴らします。音の高さは次の音から変わるので、なめらかに滑る音ではなく「ピッピッ」と続く音になり、再生コマンドの起動ぶん少し遅れます。全体の音量 `master` = 0.12 は同じです。p5.js 版と同じく、最初のクリックかキーで鳴り始めます。ブロック図の箱は英語が入るよう少し広くしています。
- **15 カメラ映像を電荷に**：格子は同じ 80 × 60 で、カメラは ffmpeg 経由で 80 × 60 で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像（計算結果も同じ）になります。電気力線は細い線です。`S` の保存は PNG ではなく SVG です。
