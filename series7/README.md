# シリーズ7：音楽情報処理 ─ Haskell コード集

音階・リズム・音色・メロディを数で扱い、音楽をコンピュータで分析・生成するスケッチ 16 本を、Haskell（gloss）に移植したコード集です。鍵盤と周波数の関係から始めて、ステップシーケンサー、ユークリッド・リズム、ビート検出、倍音と ADSR、クロマ、スペクトル重心、マルコフ連鎖による作曲、自動採譜、コード進行、キー推定、FM 音源、音の指紋まで順に進みます。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series7/

## 使い方

```sh
cabal run s7-00
```

番号を変えると別のスケッチが動きます（`s7-05`、`s7-12` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 🎤 マイクは `ffmpeg` で読みます。使えないときはデモの信号で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。08 の曲名は Twinkle Star、Frog Song、Butterfly です。
- **図形**：角の丸い長方形は、ふつうの長方形で描いています。
- **音**：Web Audio の代わりに、波形のファイルを再生コマンドで鳴らします。発音まで少し遅れ、同時に 8 音までで、音はどれも鳴らしたあと減衰します。音のためのクリックは不要です。
  - 少し先を予約するしくみはなく、時刻が来たフレームで鳴らすので、リズムは p5.js 版より少しよれます。
  - 02 のドラムにはノイズと音程の変化がなく、高い音や四角い波の短い音で代用しています。
  - 05 は連続音を作れないので、0.12 秒ごとの短い音をくり返し、音量を ADSR にしたがって変えます。一度に鳴らす倍音は強い順に 4 つまでです。
  - 14 の音は周波数変調そのものではなく、ベッセル関数で求めた側波帯のうち強い 7 つまでのサイン波の和です。変調が浅くなっていく様子は、高い側波帯ほど短く鳴らすことで近似しています。スペクトルは実際の音を調べたものではなく、同じ式から計算して棒で表示します。
- **マイク**：マイクが使えないときは止まらずにデモの信号で動きます。波形は 22050 Hz、スペクトルは 512 点で固定で、1 個が約 43 Hz です（p5.js 版は 06・13 が約 12 Hz、07 が約 23 Hz）。
  - 06・13 は低い音の半音を区別できないので、低音の音名は p5.js 版より不正確です。
  - 09 の自己相関は p5.js 版と同じく波形から計算しますが、窓は 512 サンプル（約 23 ms、p5.js 版は 2048 サンプル）なので、低い音はやや不安定です。
- **03**：p5.js 版では 1〜4 のお手本がマウスの位置ですぐ上書きされますが、こちらはマウスを動かして値が変わるまで残ります。
- **残像**：gloss は毎フレーム描きなおします。10・12 の粒の残像は、数フレーム前の位置を薄く重ねて再現しています。
- **12**：長音階では粒が画面の右に出てしまうので、音の番号の範囲に合わせて横の位置を決めます。
- **15**：スペクトログラムは 320 × 160 のピクセル画像を 4 倍にして表示します（高さ 640、p5.js 版は画面の高さ − 120）。ピークは丸ではなく 1 マスの黄色い四角です。緑の線は 400 本までです。
