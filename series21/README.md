# シリーズ21：ロボティクス ─ Haskell コード集

ロボットを「感じて・考えて・動く」機械として組み立てる 16 本を、Haskell（gloss）に移植したコード集です。アームの順運動学と逆運動学から始めて、差動二輪ロボットの制御、ポテンシャル法・A*・RRT による経路計画、LiDAR、パーティクルフィルタ、カルマンフィルタ、PID のライントレース、群ロボット、音とカメラの作品へ進みます。すべて 2D の簡易シミュレーションで、どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series21/

## 使い方

```sh
cabal run s21-00
```

番号を変えると別のスケッチが動きます（`s21-07`、`s21-15` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。実行したら、まず画面を 1 回クリックします。
- 📷 カメラは `ffmpeg` で読みます。使えないときは動く合成映像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。式の記号も ASCII にしました（ω は `w`、θ は `t`、η は `eta`、Pᵀ は `P^T` など）。行が長いものは 2 行に分けています。
- **画面の大きさ**：1280 × 800 に固定です（p5.js 版はウィンドウいっぱい）。
- **四角の角**：角丸（台座、パネル、ロボットの胴体、目印、障害物）は普通の四角です。
- **マウス**：マウスを動かす前の位置は、画面の左上ではなく中央です。02・15 では「まだ動かしていない」の判定に中央 (0, 0) を使います。
- **乱数の種で決まる配置（06 の 1、09、10）**：種は同じ値に固定していますが、乱数の作り方が違うので、配置は p5.js 版と同じ形にはなりません。
- **00**：作業空間は点を 1 つずつ描かず、2.5 ドット角のマスに数えた画像にして表示します。そのぶん p5.js 版より少し粗く見えます。
- **10**：粒子は円ではなく小さな六角形で描きます（5000 個でも速く描くため）。重みの計算だけ、桁が足りないので Double を使います。
- **12**：画面に見せるコースは太い帯の図形で、センサーが読むのは同じ線を 1 画素 1 バイトで塗った別の画像です（p5.js 版は 1 枚の画像を両方に使う）。
- **14**：音は Art.Sound で鳴らします。発音まで少し遅れ、同時に鳴るのは 8 音までです。モーター音は連続音ではなく 0.1 秒ごとの短い音の連なりで、周波数は 10 Hz、音量は 0.05 きざみに丸めます。ローパスフィルタはありません。衝突音は本物のノイズではなく、周波数がそろわない 4 つの音を同時に鳴らします。
- **15**：カメラは ffmpeg で読みます（`Art.Device`）。カメラがないときは「カメラ待ち」のままではなく合成映像で動きます。この映像には明るい塊があるので、明るい所を追うモードでは腕は映像を追います。マウスが目標になるのは、塊が見つからないとき（色モードなど）です。
