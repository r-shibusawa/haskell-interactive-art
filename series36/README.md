# シリーズ36：光学 ─ Haskell コード集

光はまっすぐ進み、鏡ではね返り、ガラスで折れ曲がり、波として重なり合って縞や色をつくる。反射・屈折・レンズの結像から、干渉・回折・偏光、虹・色・カメラまで、光学を 2D の光線追跡とピクセル計算で体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series36/

## 使い方

```sh
cabal run s36-00
```

番号を変えると別のスケッチが動きます（`s36-07`、`s36-14` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 📷 カメラは `ffmpeg` で読みます。使えないときはカラーバーの画像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は短い英語です。θ や λ も `th`、`lam` と書きます。14 より小さい文字は 14 にそろえ、長い説明は行を分けたので、説明パネルの大きさや位置を少し変えています。
- **加算合成**：gloss には `blendMode(ADD)` がありません。03・04・11 の光線は半透明の重ね描きなので、重なっても白くならず、線の色に近づきます。04 の入射光と、ガラスに入った直後の重なった部分は白に近い色で描いています。
- **05**：光をマス目（3.6 px）に足し算して表示するので、p5.js 版より線が粗く見えます。足し算そのものは p5.js と同じ考え方で、火線は同じ形に出ます。
- **06**：計算の粗さ `cell` は 3 ではなく 3.2 です。文字が読めるように、上に暗い帯を敷いています。
- **10**：像の切り抜き（clip）の代わりに、像を描いたあとセンサーのまわりを背景色でおおいます。穴の両側の板は、D が大きくて高さが負になるときは描きません（p5.js では逆向きに伸びて枠の外へ出ます）。
- **12**：重なりは合成の機能ではなく、同じ 24 個の同心円の式をピクセルごとに計算します（3.6 px のマス目）。
- **13**：Web Audio の代わりに波形のファイルを再生コマンドで鳴らすので、発音まで少し遅れ、同時に 8 音までです。最初にクリックしなくても音が出ます。
- **14**：描きためる層は 3.6 px のマス目なので、p5.js 版より輪郭が粗くなります。その代わり、描いた絵は消えません。S の保存は PNG ではなく SVG です。
- **15**：カメラが使えないときの画像は p5.js と同じカラーバーと格子です。
- **小数の計算**：`Float` の桁落ちを防ぐため、03 の 2 次方程式は桁落ちしにくい形で解き、07 の強度の計算だけ `Double` を使います。光線が同じ面にまた当たらないための小さな距離は 1e-6 ではなく 1e-3 です。
