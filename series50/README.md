# シリーズ50：ファジィ理論 ─ Haskell コード集

「背が高い」「やや暑い」「かなり近い」― はっきり線を引けない言葉を、0 か 1 ではなく 0〜1 の「所属度」で扱うのがファジィ理論です。メンバーシップ関数と演算、言語変数とヘッジ、ファジィ関係と拡張原理から、マムダニ型・高木-菅野型の推論と非ファジィ化まで、所属度・規則の強さ・集約した形・重心を本当に計算して見せるコード集です。倒立振子と車庫入れのファジィ制御、ファジィクラスタリング、画像、意思決定、音とカメラまで。p5.js 版と同じ計算（折れ線の区間ごとに正確に積分する重心、4 次のルンゲ＝クッタ法の運動方程式、本当の更新式のファジィ c-平均法）を Haskell（gloss）で書き直し、計算はすべて倍精度（`Double`）で行っています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series50/

## 使い方

```
cabal run s50-00
```

番号を変えると別のスケッチが動きます（`s50-01`、`s50-15` など）。どのスケッチも一番下に「ファジィの道具」（メンバーシップ関数・推論・非ファジィ化）が入っています。🔊 音を使うスケッチ（14）は、最初のクリックかキーで鳴りはじめます。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です（言葉は cold / pleasant / hot、ヘッジは very / somewhat など）。記号は ASCII で書きます（μ は `mu`、α は `alpha`、Σ は `Sum`、∫ は `int`、∘ は `o`、≥ は `>=`、℃ は `C`、✓ は `OK`）。長い説明は 2 行に分け、そのぶんグラフや表の位置を少しずらしています（00・01・02・05・08 など）。
- **自己テスト**：p5.js 版と同じ手で計算できる値（全部で 118 項目、同じ許容誤差）を起動時に照合します。結果は端末に出し、画面左下にも `Self-test OK 7 / 7` のように合格数を表示します。
- **塗りつぶし**：gloss の `Polygon` は凸の形しか正しく塗れないので、曲線の下・切った後件・集約した形・面積二等分の左側は細い縦の台形を並べて塗ります（02・03・05・06・07・10・14）。
- **計算をとっておく**：06 の出力の曲面（40 × 40 のピクセル画像）、08 の誤差、12 の処理した画像は、設定が変わったときだけ計算し直します。
- **04 ファジィ関係**：自動で進む速さはフレーム数ではなく経過時間で数えます（60 fps なら p5.js と同じ）。
- **09 倒立振子**：成績の表（はじめの角度から 10 秒のファジィと PID の比較）は、規則の表・↑↓・X・D を変えたとき、1 フレーム 300 歩ずつ何フレームかに分けて計算します。計算中は「...」と表示します。
- **10 車庫入れ**：軌跡は 1 台 400 点まで、全部で 3000 点を超えたら細い線で描きます。向きの集合の名前は中心の角度（0・60・80・90・100・120・180）で表示します。70 通りの出発点の成績は p5.js 版と同じく起動時に 1 回計算します。
- **12 ファジィ画像処理**：テスト画像は自分で画素を塗って作ります（アンチエイリアスなし、「FUZZY」は 5 × 7 の点の字）。そのため画素の値は p5.js 版と少しちがいます。計算（fuzzify・INT・エッジ）は同じです。
- **14 ファジィ作曲**：Web Audio の代わりに Art.Sound の `playTone` で 1 音ずつ鳴らします（ブラウザの圧縮器はありません）。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。カメラが無いときは同じテスト画像を使います。`S` の保存は PNG ではなく SVG です。
