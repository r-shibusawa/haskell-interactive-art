# シリーズ47：結び目理論 ─ Haskell コード集

ひもの両端をつないだ輪は、どこまでほどけるのか。結び目と絡み目の図を描き、ライデマイスター移動で変形し、交点の数・ねじれ数・絡み数・彩色・アレクサンダー多項式・ジョーンズ多項式といった「不変量」を図のデータ（PD 符号）から本当に計算して見分けるコード集です。組みひも・トーラス結び目・連結和・結び目表、ザイフェルト曲面と DNA、音とブラシまで。p5.js 版と同じ計算（交点の検出と PD 符号、整数行列の対角化、ベアイス法の多項式の行列式、カウフマン括弧の状態和）を Haskell（gloss）で書き直し、係数はすべて整数（`Integer`）で正確に計算しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series47/

## 使い方

```
cabal run s47-00
```

番号を変えると別のスケッチが動きます（`s47-01`、`s47-15` など）。どのスケッチも一番下に「結び目の道具」（不変量の計算）が入っています。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。結び目の名前も英語（Trefoil、Figure-eight knot など）。記号は ASCII で書きます（Δ は `D`、⟨K⟩ は `<K>`、σ₁⁻¹ は `s1^-1`、t² は `t^2`、t^(−1/2) は `t^(-1/2)`、≠ は `!=`、✓ は `OK`）。長い多項式・ガウス符号・説明文は、項や単語の切れ目で折り返します。そのため 06・10・12・13 では表やグラフ、説明の欄の位置を少しずらしています。
- **自己テスト**：00・05・06・07・10・11 では、起動時に p5.js 版と同じ 19 項目を照合します（Knot Atlas の約束 A = t^(−1/4) で知られている値）。結果は端末に出し、画面にも `Self-test OK 19 / 19` のように合格数を表示します（11 は p5.js 版ではコンソールだけ）。
- **計算のしかた**：多項式と行列の計算は、すべて整数（`Integer`）で正確に行います。p5.js 版は括弧の計算結果をキャッシュして毎フレーム呼び出しますが、こちらは図や設定が変わったときにだけ計算して覚えておきます。07 では、結び目を選んだときに 2^n 通りの状態のループの数を全部数えておきます。
- **3D（00・03・09）**：WEBGL の代わりに、管を四角形に分けて自分で回転・透視投影し、奥から順に塗ります（画家のアルゴリズム。裏向きの面は描きません）。光の当たり方は簡単な拡散光と鏡面光で、p5.js 版の照明とは少し違います。
- **03 ほどく**：くり返しの計算は毎フレーム、↑↓ で決めた回数（1〜12）だけ行います。交点の数は、p5.js 版と同じく 15 フレームごとに数えます。
- **09 トーラス結び目**：管の点の数は、輪が gcd(p, q) 本あるとき 1 本あたり 360 / gcd 点にして、描く面の数をおさえています。トーラスの網目は管より先に描くので、管の手前には来ません。p, q を 6 近くまで上げると、キーを押したときの再計算（約 30 交点のアレクサンダー多項式の正確な計算）に少し時間がかかります。
- **12 ザイフェルト曲面**：gloss の `Polygon` は凸の形しか正しく塗れません。そこで円板は輪郭を 90 点ほどに間引いてから三角形に分けて塗り（耳を切り取る方法）、ちょうネクタイ形の帯は辺が交わる点で 2 つの三角形に分けて塗ります。
- **13 DNA の結び目**：正規分布の乱数はボックス・ミュラー法で作ります。
- **14 結び目を演奏する**：Web Audio の代わりに Art.Sound の `playTone` で 1 音ずつ鳴らします（ブラウザの圧縮器はありません）。p5.js 版と同じく、最初のクリックかキーで鳴りはじめます。
- **15 結び目ブラシ**：帯の丸いつなぎ目の代わりに、線分を両はしで少しのばして曲がり目をうめます。カメラは ffmpeg 経由で読みます。カメラが無いときは p5.js 版と同じく無地です。`S` の保存は PNG ではなく SVG です。
