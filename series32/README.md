# シリーズ32：タイリング ─ Haskell コード集

すき間なく・重ならずに平面を埋める。正多角形とアルキメデスの平面充填、エッシャー風の変形タイル、五角形、ペンローズ・タイルと黄金比、2023 年の「帽子」タイル、ドミノとパズル、双曲平面と球面までを動かしながら体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結していて、分割（デフレーション）、バックトラック、鏡映・メビウス変換、凹んだ多角形を凸の部分に分ける処理も、使うスケッチの一番下の「道具」に入っています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series32/

## 使い方

```sh
cabal run s32-00
```

番号を変えると別のスケッチが動きます（`s32-07`、`s32-12` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。最初に 1 回クリックするかキーを押すと音が出るようになるのは p5.js 版と同じです。
- 📷 カメラは `ffmpeg` で読みます。使えないときはデモの映像で動き、画面にそのことが表示されます。
- どのスケッチも S で画面を SVG に保存します。

## p5.js 版との違い

- 画面の文字は英語です（gloss の文字は ASCII のみ）。パネルの角丸はありません。
- 07・08・09 の F は、p5.js 版では 1.5〜2 秒画面を止めて一気に計算しますが、ここでは 1 フレームに 20 ミリ秒ずつ、同じ時間だけ全力で進めます。途中経過が見えます。
- 01・04・05・13・15 のタイルの境目は、線を引く代わりにタイルを少し内側へ縮めて背景を見せています（図形の数を減らすため）。02・03・12 の境目は細い線です。
- 05 は図形の数が多くなりすぎるとき（分割 8 回など）円弧を省略し、そのことを画面に表示します。
- 02・03・07・12 の凹んだタイルは、凸の部分に分けて塗っています。実際のウィンドウでは継ぎ目は見えませんが、保存した SVG には細い継ぎ目が見えることがあります。
- 08 の画像は 1 辺 282 画素までです。大きさ 141 をこえると 1 マス = 1 画素ではなく、間引いて表示します（計算はすべてのドミノで行います）。
- 12 の球面は WEBGL の代わりに、自前の回転・透視投影と奥から順に塗る方法（画家のアルゴリズム）で描きます。向こう側を向いた面は描きません。
- 13・14 の音はファイルを作って再生するので、少し遅れて鳴ります。14 の演奏では 1 列で同時に鳴る音は 8 音までです。
- 15 のカメラのない場合のデモ映像は、ライブラリの共通のものです（p5.js 版の色の玉とは絵がちがいます）。
