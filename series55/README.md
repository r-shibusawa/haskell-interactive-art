# シリーズ55：熱力学 ─ Haskell コード集

「温度って何？」「熱はなぜ熱い所から冷たい所へしか流れない？」― 熱・温度・エントロピーを、**分子のふるまいから**確かめるコード集です。箱の中の分子の衝突から温度と圧力を測り、熱伝導・相変化、PV 図の 4 つの過程とカルノーサイクル・ヒートポンプ、混合と不可逆性、アインシュタイン固体の場合の数、ボルツマン分布、マクスウェルの悪魔、イジング模型の相転移、ファン・デル・ワールス気体、ブラウン運動まで、どれも**本当に計算した**シミュレーションです。p5.js 版と同じ計算（セルリストで衝突を調べる剛体円板の気体、陽解法の熱伝導、台形の数値積分、正確な整数で数える場合の数、種つき乱数のメトロポリス法、二分法）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。分子のスケッチは換算単位（ボルツマン定数 k = 1、分子の質量 m = 1）で、2 次元なので「体積」は面積 A、温度は ⟨½mv²⟩ = kT です。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series55/

## 使い方

```
cabal run s55-00
```

番号を変えると別のスケッチが動きます（`s55-01`、`s55-15` など）。どのスケッチも一番下に「熱力学の道具」（乱数・剛体円板の気体・グラフ・自己テストなど）が入っています。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（ヘッドホンは特に注意。全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。記号は ASCII で書きます（⟨v²⟩ は `<v^2>`、η は `eta`、γ は `gamma`、τ は `tau`、≈ は `~`、✓ は `OK`）。グラフの目盛りの文字は 12 px から 14 px に大きくしました。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 92 項目）。結果は端末に出し、画面右下にも `Self-test OK 6 / 6` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、引く順番もそろえたので、乱数の列は p5.js 版と同じです。ただし `log`・`cos`・`exp` は C のライブラリと JavaScript で最後の 1 ビットが違うことがあり、分子の衝突のように小さな差が大きく育つ計算は、しばらくすると p5.js 版とは別の（統計的には同じ）動きになります。自己テストの数（例：01 の PA/(NkT) = 1.052、p5.js 版は 1.045）も少し違うことがありますが、すべて同じ許容誤差の中に入ります。`R` などの種なしのやり直しは `Date.now()` の代わりに `randomRIO` で種を決めます。
- **分子の気体（00・01・10・13・14）**：位置と速度は unboxed 配列で、1 コマ分の小さなステップをまとめて書きかえます（セルリストの順番・壁と衝突の計算の順番は p5.js 版と同じ）。p5.js 版の `onHit`・`barrier`・`after`（壁に当たったとき・仕切り・押しもどしの後に呼ぶ関数）は、それを使うスケッチの道具の中に直接書いてあります。
- **14 熱の音**：Web Audio の代わりに Art.Sound の `playTone` で鳴らします。音を鳴らす衝突の選び方（乱数・1 コマ 4 回まで）は p5.js 版と同じですが、音を 1 つずつ再生コマンドで鳴らすので、「コツ」は選ばれたうちの最初の 1 つを 2 コマに 1 回まで鳴らします。カルノーサイクルの持続音は、0.25 秒の音を 1 秒に 4 回くり返して代わりにします（音色は過程ごとに正弦波・三角波・正弦波・矩形波、ローパスフィルタはなし）。最初のクリックは要らず、キーかクリックで音が始まります。
- **塗りつぶし**：gloss はへこんだ多角形を塗れないので、04 の仕事の面積・12 の等面積の 2 つの領域と共存曲線の内側は細いたての帯で、05 の PV 図・TS 図の囲まれた面積は中心からの三角形で塗ります。角の丸い箱は普通の長方形です。
- **04 PV 図**：残しておく過程は 60 個まで（p5.js 版は全部）。500 点より多い線は描くときだけ間引きます。
- **文字の位置**：英語の説明が長くなるので、02 の F モードの熱の流れ、07 の逆回しの表示、05 のカルノーの限界と色の説明、06 の電気代のまとめ（3 行）などは、p5.js 版と少しちがう場所に書きます。05・12 の小さい数は `1.8e-15` のような書き方です。
- **11 イジング模型**：p5.js 版と同じ 128 × 128、1 コマ 2 スイープで、受け入れる確率が 1 のときは乱数を引きません（自己テストの ⟨|m|⟩ = 0.956 も同じ）。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像（明るい円 2 つと棒）になります。`S` の保存は PNG ではなく SVG です。
