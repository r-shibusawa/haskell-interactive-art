# シリーズ15：フロー・マッチング・並列・オンライン ─ Haskell コード集

水をどれだけ流せるか（最大フロー）、誰と誰を組ませるか（マッチング）、みんなで同時に計算するには（並列）、未来を知らずにどう決めるか（オンライン）。それぞれのアルゴリズムを、動かして確かめるコード集です。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series15/

参考：Cormen ほか『Introduction to Algorithms』

## 使い方

```
cabal run s15-00
```

番号を変えると別のスケッチが動きます（`s15-00` 〜 `s15-15`）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。∞ は inf、Θ は Theta、T₁ は T1、T∞ は Tinf と書きます。読みやすさのために文字は 14 以上にしました。
- **角の丸み**：長方形やマスの角は丸くなりません。
- **点線（03・04・05）**：短い線を並べて描きます。
- **音（13・14）**：波形のファイルを再生コマンドで鳴らすので、発音まで少し遅れ、同時に 8 音までです。音を出すための最初のクリックは不要です。
- **06 ハンガリー法**：JavaScript のジェネレーター（`function*`）の代わりに、スケッチの下にある小さな `Gen` を使います。マスの中の「残り」は `r=3` のように短く書きます。
- **08 並列ループと競合**：タイムラインの横のずれを少しつめ、ヒストグラムの目盛りは結果が 8 種類以下のときだけ書きます。
- **09 並列の行列かけ算**：n = 16 では C の数字がマスに入らないので、マスには色だけを出し、マウスを乗せると下に値を出します。同じ行の k と時刻は `3@5` のように短く書きます。
- **10 並列マージ**：n = 64・128 では棒の下の数字を省きます。段ごとの棒が出力の棒に重ならないよう、少し下に置きました。
- **14 水路をデザインする**：水の粒は 3000 個までです。
- **15 プッシュ再ラベル法**：右の記録は 2 行までで、はみ出す分は省きます。同じ高さの点が重ならないよう、a と b、c と d を少し左右にずらしました。
