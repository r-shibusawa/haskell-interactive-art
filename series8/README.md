# シリーズ8：複雑ネットワーク（グラフ理論）─ Haskell コード集

点と線でつながる世界。グラフの基本、BFS / DFS、ダイクストラ法と A*、ランダムグラフ、スモールワールド、ハブ、感染、ページランク、コミュニティ検出、音楽やマイクとの組み合わせ、パーコレーション、巡回セールスマン問題までを体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series8/

## 使い方

```sh
cabal run s8-00
```

番号を変えると別のスケッチが動きます（`s8-07`、`s8-12` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 🎤 マイクは `ffmpeg` で読みます。使えないときはデモの信号で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：英語にし、長い説明は 2〜3 行に分けています。
- **04・05・14**：`randomSeed` の代わりに `System.Random` の `mkStdGen` を使います。同じ seed なら同じ乱数の列になるしくみは同じですが、数の列そのものは p5.js 版と異なります。
- **06**：力の計算は同じですが、点が増えると反発で画面の外まで広がるので、全部の点が左側に入るように表示だけ自動で縮めます（点と線の位置関係は同じです）。
- **08**：サーファーは 500 人までです。
- **10**：音の予約（0.1 秒先まで）はせず、時刻が来たフレームで鳴らします。音は外部コマンドで再生するので少し遅れます。
- **11**：マイクが使えないときはデモの信号で動き、画面にそのことを表示します（p5.js 版は音量 0 のままです）。
- **12**：`background(…, 50)` の残像は、直前 3 フレームの点と線を薄く重ねて再現します。点はクリックでも 300 個までです（p5.js 版の上限はドラッグのときだけです）。`S` は PNG ではなく SVG で保存します。
