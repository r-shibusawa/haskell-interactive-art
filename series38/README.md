# シリーズ38：トロピカル幾何学 ─ Haskell コード集

「足し算 = min、掛け算 = +」という奇妙な算数（トロピカル半環）から、折れ線でできた「曲線」が生まれる。トロピカル多項式と曲線、ニュートン多角形との双対性、ベズーの定理、アメーバ、そして max-plus 代数の応用（最短経路・周期スケジュール）までを 2D で体験するコード集です。p5.js 版と同じ計算を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series38/

## 使い方

```
cabal run s38-00
```

番号を変えると別のスケッチが動きます（`s38-01`、`s38-15` など）。音を使う 13 は、実行したらまず画面を 1 回クリックします。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。⊕ は `(+)`、⊗ は `(x)`、⊘ は `(/)`、∞ は `inf`、τ は `tau`、λ は `lambda` と書きます。長い説明は行を分け、パネルの角は丸くありません。文字が p5.js 版より幅広いので、一部のラベルは位置や書き方を変えています（10・13 のノードの中は τ の値だけ、01 の凸包の点は高さだけ）。
- **02・11・14・15 の領域の色**：透明な画像を重ねる代わりに、背景と混ぜた色を計算して 1 枚の画像にしています。
- **07 アメーバ**：点を画面に焼きつけるのではなく、3 px のマスごとに点の数を数えて画像にします。丸い点の代わりに四角いマスなので少し粗く見えます。1 マスの数は 40 で止まります。
- **13 ダイヤを聴く**：音は OS の再生コマンドで鳴らすので、発音までに少し遅れがあります。
- **14 ブラシ**：`S` の保存は PNG ではなく SVG です。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。ffmpeg やカメラが無いときは p5.js 版と同じくノイズで動きます。
