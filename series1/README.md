# シリーズ1：p5.js でつくるインタラクティブアート ─ Haskell コード集

マウス・キーボード・音・マイク・カメラを使ったインタラクティブアートの入門 16 本を、Haskell（gloss）に移植したコード集です。円がマウスについてくるだけのスケッチから、パーティクル、音の出るボール、マイクやカメラに反応する作品、演奏を止めずにコードを書きかえるライブコーディングまで、順に進みます。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series1/

## 使い方

```sh
cabal run s1-00
```

番号を変えると別のスケッチが動きます（`s1-07`、`s1-14` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 🎤 マイク・📷 カメラは `ffmpeg` で読みます。使えないときはデモの信号や映像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の大きさ**：00・01・05・12 は p5.js 版の固定サイズ（600 × 400 など）ではなく、1280 × 800 のウィンドウに合わせています。05 はウィンドウいっぱいにマス目を並べます。
- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。09 の鍵盤は Do Re Mi … です。
- **保存**：S キーの保存は PNG ではなく SVG です。
- **描いたものを残すしくみ**：gloss は毎フレーム描きなおします。
  - 02・03 は線を 7500 本まで覚えていて、超えると古い線から消えます。
  - 04 は古い線を 356 × 222 のピクセル画像に焼きつけて残すので、古い線は少し粗くなります。
  - 06・07・09・10・13・14 の残像は、数フレーム前の位置を薄く重ねて再現しています。
  - 06 は同時に 850 粒までで、超えると古い粒から消えます。
- **音**：Web Audio の代わりに、波形のファイルを再生コマンドで鳴らします。発音まで少し遅れ、同時に 8 音までです。
  - 08 の音は連続音ではなく、短い音のくり返しです。表示する波形は実際の音を調べたものではなく、周波数と音量から計算しています。
  - 14 のドラムにはノイズと音程の変化がなく、短い音で代用しています。cutoff はフィルタではなく、音色を丸い波形に切りかえる近似です。`wave` の場面の波形は、鳴らしている音から計算しています。
- **マイク**：マイクが使えないときは止まらずにデモの信号で動きます。
- **14 ライブコーディング**：
  - JavaScript を実行できないので、コード欄の命令は `bpm` `drum` `synth` `scene` `hush` を読む小さな言語です。`let` や `visual(v => ...)` は使えません。
  - L05・L06・L08 の映像は `scene('stars')` `scene('spin')` `scene('orbit')` として組みこみました。自分の映像は `Main.hs` に場面を足して書きます。
  - コード欄の文字は半角英数字のみです。レシピは PageUp / PageDown で読みこみます（内容は英語に訳してあります）。
  - 前回のコードは保存されません。Mac の ⌘ + Enter は使えないので、Ctrl + Enter か F5 を使います。
  - 映像の変数 `v.level`（全体の音量）はありません。
- **15 画像分類**：Web 上の Teachable Machine のモデルは読みこめません。代わりに、1〜4 キーでカメラの映像をその場で学習し、クラスごとの平均の画像にいちばん近いものを選ぶ小さな分類器を使います。学習はウィンドウを閉じると消え、クラスは 4 つまで、名前は Class 1〜4 です。p5.js 版のような深層学習ではないので、明るさや配置の違いで見分けます。また、音のためのクリックは不要です。
