# シリーズ62：決定木 ─ Haskell コード集

「はい/いいえ」の質問を重ねてデータを分ける、いちばん説明しやすい機械学習 ― 決定木を**自分の手で作って確かめる**コード集です。20 の質問とエントロピー・情報利得から始めて、手で作る木、ID3 と「テニスをする？」の表、CART と領域分割、深さと過学習、コスト複雑度剪定と交差検証、回帰木、そしてバギング・ランダムフォレスト・AdaBoost・勾配ブースティング、特徴量の重要度、ほかの方法との境界の比べ方まで、どれも**ライブラリを使わずに本当に学習した**シミュレーションです。p5.js 版と同じ手順（全部の特徴量 × 全部の中点を調べる CART、ID3、いちばん弱い枝から刈る剪定と k 分割交差検証、2 乗誤差の回帰木、ブートストラップと OOB 誤差、特徴量を間引くランダムフォレスト、切り株の AdaBoost、縮小つきの勾配ブースティング、不純度の減少と並べ替えの重要度、k 近傍法と自作のロジスティック回帰）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。種つきの乱数も p5.js 版と同じ列を同じ順に引くので、データ・木・OOB 誤差・正解率は p5.js 版と同じ値になります。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series62/

## 使い方

```
cabal run s62-00
```

番号を変えると別のスケッチが動きます（`s62-01`、`s62-15` など）。どのスケッチも一番下に「決定木の道具」（エントロピーとジニ、CART、回帰木、剪定、フォレスト、ブースティング、木の図、種つき乱数、自己テストなど）が入っています。色：クラス A = オレンジ、B = 青、C = 緑。木の図は「x1 <= しきい値？」に「はい」なら左、「いいえ」なら右。[A|B] はそのノードの件数。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や数学記号を出せないので、説明は短い英語で、記号は ASCII で書きます（≤ は `<=`、√ は `sqrt`、✓ は `OK` など）。動物の名前・天気などの表の言葉も英語にしました。木の図の箱の文字と、グラフの目盛りの文字は 11〜12 px から 14 px に大きくし、そのぶん箱を少し広く（最大 150 px）しています。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 100 項目）。結果は端末に出し、画面右下にも `Self-test OK 6 / 6` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、乱数の列を 1 本だけ持って引く順番もそろえた（乱数を順に引く小さなモナド `R`）ので、データ・ブートストラップ・特徴量の間引き・シャッフルは p5.js 版と同じです。`Math.random()` を使う所（00・14 のスペースなど）は `randomRIO` です。
- **CART の速さ**：根で特徴量ごとに点を 1 回だけ並べ、子にはその並びを分けて渡します（毎回並べ直すのと同じ順になるので、選ばれる分割は同じ）。
- **絵の作り直し**：p5.js 版が `dirty` のときだけ塗り直す領域の絵は、木や深さが変わったときに `World` に作っておき、毎コマは描くだけです。
- **14 木をたどる音**：Web Audio の予約の代わりに、その時刻になったコマで Art.Sound の `playTone`（三角波、和音は正弦波）を鳴らします。音量は p5.js 版の `MASTER` × 音量と同じ大きさ（0.06 と 0.036）です。
- **15 カメラ**：カメラは Art.Device（ffmpeg 経由、左右反転）で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像（赤い円・緑の箱・黄色の線）と見本のクリックになります。画素は unboxed 配列で持ち、点を作らずに木をたどって全画素を分類します。`S` の保存は PNG ではなく SVG です。
- **表の言葉**：00 の動物と質問、03 の「テニスをする？」の表（Outlook / Temp / Humidity / Wind / Play、Sunny / Overcast / Rain など）は英語で書きます（対応はコードの先頭）。03 の表のマスは英語が入るように少し広く（82 → 90 px）しました。
- **点線**：01・02・05・06・08・10 の点線（しきい値・いちばんよい深さ・上限の線など）は、短い線分を並べて描きます。08 の 1 本ずつの木の境界（うすい白）は、半透明の画像を重ねる代わりに領域の絵の色に直接混ぜます（見た目は同じ）。
- **02 の Z（1 本戻す）**：前の木をまるごと持っておいて戻します（結果は同じ）。
- **12 特徴量の重要度**：並べ替え重要度は「1 コマに 1 列」ではなく「1 コマに 1 回のシャッフル」（1 列 = 3 コマ）で少しずつ計算します。乱数を引く順は同じなので、値は p5.js 版と同じです。
- **13 木の得意と苦手**：k 近傍法の境界の絵と正解率は、データか k が変わったあと約 8 コマかけて計算します（その間は `computing...`）。答えは p5.js 版と同じです。
