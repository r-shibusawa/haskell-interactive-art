# シリーズ9：位相的データ解析（TDA）─ Haskell コード集

データの「形」を数える。点群から塊と穴を見つけ、パーシステント・バーコードで記録する TDA（Topological Data Analysis）を体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結していて、リップス複体とパーシステント・ホモロジーの計算（Z2 係数の列簡約）も、使うスケッチの一番下の「TDA の道具」に入っています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series9/

## 使い方

```sh
cabal run s9-00
```

番号を変えると別のスケッチが動きます（`s9-07`、`s9-12` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 🎤📷 マイクとカメラは `ffmpeg` で読みます。使えないときはデモの信号・映像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。長い説明は短くするか、複数行に分けています。β0・β1・χ・τ は `b0`・`b1`・`chi`・`tau`、■・● は `#`・`o` で表します。文字は最小 14 の大きさにしました。
- **乱数**：`randomSeed` の代わりに `mkStdGen` を使います。同じ種からいつも同じ点群ができますが、点の位置そのものは p5.js 版と同じにはなりません。
- **マウスの初期位置**：動かす前のマウスは画面の中央にあるものとして扱います（p5.js 版は左上）。
- **04・10**：r の進み方を 1 フレームあたりではなく時間あたりで決めています（60 fps のときに同じ速さ）。
- **09**：
  - お手本 2 のノイズは `fbm2`（4 段重ね）で作ります。p5.js の `noise` とは模様が異なります。
  - しきい値の帯は角の丸くない長方形です。
- **10 の音**：連続音の代わりに 0.45 秒ごとの短い音をくり返します。同時に 8 音までしか鳴らせないので、高い音（穴）4 つと低い音（塊）4 つまでにしました。低い音は数が減るぶん、音量を 0.03 から 0.1 に上げています。画面の「鳴っている数」は生きているバーの本数のままです。
- **11 のマイク**：
  - 波形は 512 サンプル、22050 Hz です（p5.js 版は 1024 サンプル）。
  - サンプリング周波数が半分なので、τ の範囲を 2〜80 から 1〜40 にしました。およそ同じ時間の遅れになります。
  - マイクが使えないとき、p5.js 版は何も出ませんが、こちらはデモの信号で動きます。
- **12**：S の保存は PNG ではなく SVG です。
- **14**：
  - 計算はスペースを押してすぐ終わります（p5.js 版は数秒かかります）。
  - 点を奥から順に描きます（p5.js 版は順番を気にしません）。
- **15**：
  - カメラが使えないときはデモの映像で動きます。
  - 2 値化した画像は 1 枚のピクセル画像で描きます。
- **配置の調整**：大きくなった文字が重ならないように、次の配置を変えています。
  - 04：棒の説明をバーコードの下に移します。
  - 07：表の列を左に寄せ、形の名前を短くします（「3 つの輪（オリンピック）」は `3 rings`）。
  - 09：凡例を 2 段に分けます。
  - 13：棒の説明を 2 行に分けます。
  - 14：`Long H1 bars` の行をバーコードの目盛りの下に下げます。
