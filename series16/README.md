# シリーズ16：行列・線形計画・FFT・数論 ─ Haskell コード集

参考：Cormen ほか『Introduction to Algorithms』

「行列演算」「線形計画法」「多項式と FFT」「整数論的アルゴリズム」を、動かして見る 16 本を Haskell（gloss）に移植したコード集です。LUP 分解・シンプレックス法・FFT のバタフライ・ユークリッドの互除法・RSA 暗号・ミラー–ラビン法などを、1 ステップずつ止めながら観察できます。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series16/

## 使い方

```sh
cabal run s16-00
```

番号を変えると別のスケッチが動きます（`s16-07`、`s16-13` など）。

- ほとんどのスケッチは **スペースで 1 ステップ、A で自動再生、R でやり直し** です。
- 画面の文字は英語です。L/R は左右の矢印キー、Up/Down は上下の矢印キーのことです。
- 🔊 の音は `afplay`（macOS）または `aplay`（Linux）で鳴らします。

## p5.js 版との違い

- **1 手ずつ止まるしくみ**（00・01・04）：JavaScript のジェネレーター（`function*` と `yield`）の代わりに、各スケッチの下にある小さな `Gen` を使います。結果は「状態の遅延リスト」になり、スペースで 1 つずつ取り出します。
- **計算の型**：誤差の判定（1e-9 など）を p5.js 版と同じにするため、行列・LP・FFT の計算は `Double`（p5.js の数と同じ精度）で行い、描くときに `Float` にします。13 の BigInt は `Integer` です。
- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。ωₙ は `w_n`、x² は `x^2`、Θ は `Theta`、φ は `phi` と書きます。文字を 14 以上にそろえ、長い説明は短くして折り返します。
- **枠で切り取る**（03・04・05・06）：`drawingContext.clip` の代わりに、図の周りを背景色で塗って隠します。
- **角**：マスや枠の角は丸くなりません。
- **01**：へこんだ形はそのまま塗れないので、F の形は長方形 3 つに分けて塗ります。
- **02**：次数が 3 以上のときは A^T A と L が縦に入らないので、横に並べます。次数 5・6 はマスが小さいので、小数を省いて整数で書きます。
- **08**：入力のラベルが入るよう、回路の左の余白を広げました。
- **09**：文字が入らない細いマス（16 けた以上の逆 FFT の値、32 けたの全部）は、数字の代わりに色の濃さで見せます。数は画面の上と最後の答えで読めます。答えの検算は BigInt の代わりに `Integer` です。
- **11**：3 の緑の輪は、数字の丸に隠れないよう、丸より大きくして上に描きます。数字を読めるよう、丸の半径の下限を 14 にしました。
- **13**：入力欄は gloss にないので、自前で作りました。欄をクリックすると入力でき（Enter か欄の外のクリックで終わり）、入力中は 1〜3、スペース、F は文字になります。日本語は表示できないので、`U+3053` のように文字コードで書きます（初期の文の「こんにちは」も暗号化・復号の計算は同じです）。また、文字ごとの暗号化を横に並べると 14 以上の文字が入らないので、縦の表にしました。
- **14**：音は波形のファイルを再生コマンドで鳴らすので、発音まで少し遅れ、同時に 8 音までです。音を出すための最初のクリックは不要です。
- **15**：ロー法の数列は、表に見せる最後の 14 行といまの値だけを持ちます。
