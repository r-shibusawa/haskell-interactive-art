# シリーズ23：群と対称性 ─ Haskell コード集

「動かしても変わらない」= 対称性。その対称性どうしの掛け算のルールが「群」です。正多角形の回転と裏返し、置換、15 パズル、壁紙模様、ネックレスの数え上げ、そしてルービックキューブまで、群論の考え方を自分の手で動かして体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結していて、10〜13 のキューブの仕組みは各ファイルの下の「キューブの道具」に入っています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series23/

## 使い方

```sh
cabal run s23-00
```

番号を変えると別のスケッチが動きます（`s23-07`、`s23-12` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 📷 カメラは `ffmpeg` で読みます。使えないときは自動で動く模様を映し、画面にそのことが表示されます。

## p5.js 版との違い

- 画面の文字は英語です（gloss の文字は ASCII のみ）。上付き・下付きの数字は `r2`、`Z12`、`A^-1` のように書き、14 の音名は C、C#、… です。
- 配置は 1280×800 の窓に合わせた固定の大きさです。窓を広げても絵は中央に同じ大きさで出ます。角丸の四角は普通の四角です。
- 00：一覧の小さな図の頂点には番号を書きません（p5.js 版では 2 ピクセルほどで読めない文字です）。
- 02：表の場所を少し広げ（幅 50%）、文字が小さくなりすぎないようにしました。S3 の点の名前は丸より長いので白い文字です。
- 05：右の説明を少し左に寄せました（幅 60% から）。Zn から `2` を押したときは n を 3〜10 におさめます（p5.js 版は n = 24 のまま D24 になります）。
- 07：n = 8・k = 4 の全数調査は、配列を作り直さず重みの和で計算します（結果は同じで、一瞬止まることがほとんどありません）。
- 08・09：キャンバスに描き足す代わりに、1 周期ぶんの絵を画素のバッファ（`Data.Vector.Unboxed`）に描き、それを `pixelImage` で並べます。08 の単位が大きくて 8 万画素を超えるときは少し粗くなります。09 の帯の高さと周期は整数のピクセルにそろえました（97 と 107）。S の保存は PNG ではなく SVG です。
- 10：OpenGL の 3D ではなく `V3` と透視投影で描きます。視点はドラッグ（回す）とホイール（近づく）で、右ドラッグの平行移動はありません。回転中の層と残りの部分はそれぞれ凸な立体なので、裏向きの面を捨て、カメラから遠いかたまりを先に描くだけで正しく重なります。
- 11・12：長い手順や巡回の説明は折り返します。画面に入らない分は省きます（計算には全部使います）。
- 13：BigInt の代わりに Haskell の `Integer` を使います。
- 14：音は Art.Sound で鳴らします。発音まで少し遅れ、同時に鳴るのは 8 音までです。クリックで音をスタートする操作はいりません。
- 15：テクスチャの三角形の代わりに、画面の 320×200 の各画素がどの映像の点にあたるかを逆に計算し、4 倍に拡大して表示します（少しモザイク状に見えます）。カメラなしの模様は p5.js 版と同じ 24 個の丸と白い線を、半分の大きさ（160×120）で作ります。S の保存は SVG です。
