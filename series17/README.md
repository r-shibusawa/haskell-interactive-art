# シリーズ17：文字列・計算幾何・機械学習 ─ Haskell コード集

参考：Cormen ほか『Introduction to Algorithms』

文字列の中から言葉を探す、点や線分の「形」を計算する、データから学ぶ。文字列照合・計算幾何学・機械学習のアルゴリズムを動かして体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series17/

## 使い方

```sh
cabal run s17-00
```

番号を変えると別のスケッチが動きます（`s17-07`、`s17-13` など）。

- 文字列のスケッチ（00〜04）は、キーボードでそのまま文字を入力できます。**Tab** でテキストとパターンを切りかえます。日本語入力はオフにしてください。
- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 画面の文字は英語です。Space はスペース、Right / Left / Up / Down は矢印キーのことです。
- 計算幾何のスケッチは p5.js 版と同じ座標（左上が原点、y は下向き）で計算し、外積では y を反転して「数学の向き（左回り = +）」にそろえています。

## p5.js 版との違い

- **1 手ずつ止まるしくみ**（03・04・07・08・09）：JavaScript のジェネレーター（`function*` と `yield`）の代わりに、各スケッチの下にある小さな `Gen` を使います。アルゴリズムの書き方は同じで、結果は「状態の遅延リスト」になります。
- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。δ、π、ε、η などは d、pi、eps、eta と書きます。読みやすさのために文字は 14 以上にしました。
- **マスの角**：マスや棒の角は丸くなりません。
- **00**：お手本 4 の日本語の早口ことばは、ローマ字（`sumomomomomomomonouchi` と `momo`）にしました。入力できるのは ASCII の文字だけです（01〜04 も同じ）。
- **04**：順位の組が重ならないよう、LCP の列を少し右にずらしました。
- **05・08・09**：説明の文字が入るよう、右のパネルを少し広くしたり、タイトルの下へ下げたりしました。パネルの上をクリックしたときの扱いも、パネルの位置に合わせています。
- **06**：見つかった交差の一覧は、パネルに入る 9 組までを表示します。
- **07**：お手本 3（格子）の間隔は整数にしました。計算を `Float` で行うので、小数の誤差で「一直線」が崩れないようにするためです。同じ向きの点は、角度が完全に同じでなくても外積で判定して距離の順に並べます。
- **10**：点をまくのは全部で 1200 点くらいまでです（描く数を抑えるため）。
- **11**：天気の絵文字の代わりに `R`（雨）と `S`（晴れ）を使います。重みは小さくなるので `Double` で計算します。
- **12**：数値微分の誤差を抑えるため、座標と関数の値は `Double` で計算します。学習率には上限と下限（10^6 と 10^-9）があります。
- **13**：画面を少しずつ消す残像の代わりに、光の粒とレーダーの少し前の位置を薄く描きます。音はクリックしなくても最初から鳴ります。1 音ごとに `afplay`／`aplay` を起動するので、少し遅れることがあり、同時に鳴るのは 8 音までです。
- **15**：学習率には下限（10^-6）があります。傾きだけでなく切片が発散したときも、最初の直線に戻します。
