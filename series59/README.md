# シリーズ59：マックスプラス代数 ─ Haskell コード集

「足し算を max に、掛け算を + に」置きかえると、待ち合わせ・時刻表・生産ライン・最短経路が「1 次式」と「行列の計算」になる ― マックスプラス代数を**計算の道具として**使うコード集です。待ち合わせの算数と半環のルールから始めて、行列の積と最長経路、推移的閉包 A*、引き算のない方程式の解き方（残余）、列車ダイヤと生産ライン、固有値＝サイクル時間（カープのアルゴリズム）、過渡と周期性、遅延の伝わり方、時間付きペトリネット、min-plus と最短経路、ビタビと「脱量子化」まで、どれも**本当に計算した**シミュレーションです。p5.js 版と同じ計算（行列の積・べき・A*（正の回路の検出つき）・残余・カープのアルゴリズム・臨界グラフと固有ベクトル・べき乗法による過渡と周期・巡回性）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。ε = −∞ は `Double` の −∞ のまま持ち、⊗ は必ず `mpMul`（ε があれば ε）を通すので、NaN は一度も出ません。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series59/

## 使い方

```
cabal run s59-00
```

番号を変えると別のスケッチが動きます（`s59-01`、`s59-15` など）。どのスケッチも一番下に「マックスプラスの道具」（⊕・⊗、行列の積、A*、カープのアルゴリズム、種つき乱数、自己テストなど）が入っています。記号：a ⊕ b = max(a, b)、a ⊗ b = a + b、ε = −∞（「ゼロ」= 起きない・制約なし）、e = 0（「いち」= 待ち時間なし）。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や数学記号を出せないので、説明は短い英語で、記号は ASCII で書きます：⊕ は `(+)`、⊗ は `(x)`、ε は `eps`、+∞ は `+inf`、λ は `lambda`、A^{⊗k} は `A^k`、✓ は `OK`。グラフの目盛りの文字は 12 px から 14 px に大きくしました。
- **ε の持ち方**：p5.js 版と同じく ε = −∞ を `Double` の −∞（`negInf`）で持ち、⊗ は `mpMul`、残余は a_ij = ε の行を飛ばします。べき乗法で周期が見つからないときの λ（p5.js 版は NaN）は `Nothing` にしました。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 92 項目）。結果は端末に出し、画面右下にも `Self-test OK 6 / 6` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、引く順番もそろえた（乱数を順に引く小さなモナド `R`）ので、ランダムなグラフ・例・λ の値は p5.js 版と同じです。`Math.random()` を使うやり直し（R キーなど）は `randomRIO` で決めます。
- **再計算**：p5.js 版が `recompute()`・`analyse()` で計算し直す結果（総当たり、A^{⊗k}、λ、臨界グラフ、べき乗法など）は、キーやクリックのときに `World` に入れておき、毎コマは計算しません。
- **表示の細かい違い**：04 の A* の表のマスは数字が読めるように大きく（40 × 24、14 px）、発散したマスは `inf` と書きます。05 の x⁺ は `x+`、07 のスループット 1/λ は題名ではなく説明の行に、11 の発火時刻の表は `r/s` と詰めて書きます。08・10 の破線は短い線分を並べて描きます。
- **12 min-plus と最短経路**：ダイクストラ法の優先度つきキューは二分ヒープの代わりに `Data.Set` を使います（距離は同じ）。迷路は unboxed 配列です。
- **14 時刻表のリズム**：Web Audio の雑音＋フィルターの打楽器の代わりに、Art.Sound の `playTone` の短い音 1 つで鳴らします（キック 75 Hz 正弦波 0.15 秒、タム 130 Hz 正弦波 0.15 秒、スネア 1800 Hz のこぎり波 0.06 秒、ハイハット 7000 Hz 矩形波 0.03 秒、全体の音量 0.12）。音は 0.4 秒先まで予約しますが、鳴らすのはその時刻になったコマです（オーディオの時計での予約はできない）。キーかクリックで音が始まります。
- **15 カメラ**：カメラは Art.Device（ffmpeg 経由、左右反転）で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像（円・線・点・箱）になります。膨張・収縮・距離変換は unboxed 配列で横 → 縦の 2 回に分けて計算し、画素はなめらかにせずに拡大します。`S` の保存は PNG ではなく SVG です。
