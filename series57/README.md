# シリーズ57：四元数と八元数 ─ Haskell コード集

「3 次元の回転を、掛け算 1 回で書けないか？」― 複素数の先にある「数」、四元数と八元数を**自分で計算して**確かめるコード集です。複素数と平面の回転から、ハミルトンの i² = j² = k² = ijk = −1・交換しない掛け算・ノルムと逆元、回転を表す q v q*・オイラー角とジンバルロック・slerp・ベルトのトリック、アークボール・角速度の積分・4 次元の回転とホップの円・四元数のジュリア集合、ケーリー-ディクソン構成・ファノ平面の八元数・十六元数の零因子まで。四元数の積（ハミルトン積）・共役・ノルム・逆元・exp/log・slerp、八元数と十六元数の積（ケーリー-ディクソン構成 (a, b)(c, d) = (ac − d*b, da + bc*)）は、p5.js 版と同じく、どれも一から書いています。3D の回転は全部の頂点を q v q* で回して置き、自分で透視投影して描きます。計算は倍精度（`Double`）です。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series57/

## 使い方

```
cabal run s57-00
```

番号を変えると別のスケッチが動きます（`s57-01`、`s57-15` など）。どのスケッチも一番下に「四元数の道具」（四元数の積・共役・回転・slerp、ケーリー-ディクソンの積、3D の描画、自己テストなど）が入っています。四元数は `Q w x y z` = w + xi + yj + zk。3D の向きは x 右・y 上・z 手前（右手系）です。🔊 音を使うスケッチ（14）は**音量を小さめから**（全体の音量は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。記号は ASCII で書きます（θ は `theta`、² は `^2`、≠ は `/=`、✓ は `OK`）。小さい文字（12〜13 px）は 14 px に大きくし、長い説明は折り返したり位置を少しずらしたりしています。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種（mulberry32 を 32 ビットの整数でそのまま書き直し、乱数を引く順番もそろえた）で照合します（全部で 99 項目。p5.js 版の check の数と同じ）。`Math.hypot` も JavaScript と同じ計算で書いています。結果は端末に出し、画面右下にも `Self-test OK 7 / 7` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **3D（WEBGL）**：gloss には深さのバッファがないので、面と線を全部「奥行きと絵」の組にして奥から順に描きます（画家のアルゴリズム。長い線は短く分けて並べ、裏を向いた面は描きません）。カメラの距離は p5.js の WEBGL の標準（画面の高さ ÷ 2 ÷ tan 30°）と同じです。半透明の物体も裏の面は描かないので、p5.js 版より少しすっきり見えます。
- **07 ベルト**：壁はいつも一番奥として先に描きます。ベルトは 64 枚の四角形を奥行きで並べるので、強くねじれたところで少し重なりが乱れることがあります。
- **08 float32 の行列**：`Math.fround` の代わりに、行列の成分を更新のたびに `Float`（単精度）に通して同じ丸めを再現しています。誤差が大きくなると自動の回転が止まるのは p5.js 版と同じです。
- **10 4 次元の回転**：頂点の小さな球は半径 4 の塗りつぶした円で、辺と一緒に奥行きで並べます。
- **11 ジュリア集合**：p5.js 版は 1 コマ 12 ms まで描きますが、こちらは 1 コマ 2000 画素ずつ（`pixPerFrame`）描きます（240 × 150 なら約 18 コマで完成）。Q で変える 3 段目の解像度は、画素数の上限（8 万画素）に収めるため 360 px ではなく 320 px 幅です（1・2 段目は 160・240 px で同じ）。絵は unboxed のバイト列にためて、描いた部分だけ書きかえます。色の丸め方のちがいで 1 だけ違う画素があります。
- **12 ケーリー-ディクソン構成**：零因子さがしは p5.js 版と同じく 1 コマに少しずつ進めます（最後は 22050 組を調べて 168 組、p5.js 版と同じ）。表の ✓/✗ は `OK`/`NO` です。
- **13 ファノ平面**：表の ✓/✗ は `OK`/`FAIL`、右の表の説明は短い英語です。
- **14 回転の音**：Web Audio の 4 つの持続音の代わりに、Art.Sound の `playTone` で 0.25 秒の音を 1 秒に 4 回鳴らします（w は正弦波、x・y・z は三角波、音量 = 全体 0.15 × c² × 0.25、高さは 40〜2000 Hz）。音の高さがなめらかに移る効果（setTargetAtTime）はありません。最初のクリックかキーで音が始まります。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像（色相のグラデーション・灰色の帯・白い円）になります。gloss は画像を立方体の面にゆがめて貼れないので、見えている面ごとに 20 × 15 の色の四角形（画像から色を拾う）で描きます。`S` の保存は PNG ではなく SVG です。
- **HUD**：p5.js 版は文字を 2〜3 コマに 1 回描きなおしますが、こちらは毎コマ描きます。
