# シリーズ64：アンサンブル学習 ─ Haskell コード集

**1 つの賢いモデルより、ちがうモデルをたくさん組み合わせる** ― アンサンブル学習のコード集です。集合知と多様性予測定理、コンドルセの陪審定理、バイアスとバリアンス、相関のある平均の限界で「なぜうまくいくか」を確かめ、ちがう種類のモデルの投票、重み付き平均、スタッキング、専門家の混合で「組み合わせ方」を学び、マージンと 2 次の勾配ブースティング、ランダム化と多様性の測り方を深め、Isolation Forest の異常検知とアンサンブルで測る「自信のなさ」で使ってみて、最後は合唱とカメラの重み付き多数決まで。どれも**機械学習のライブラリを使わずにゼロから計算した**シミュレーションです。p5.js 版と同じ計算（k 近傍法、ニュートン法と L2 正則化のロジスティック回帰、ガウスのナイーブベイズ、手書きの誤差逆伝播と Adam で学習する隠れ層 1 層のニューラルネット、重みつきの切り株、チェビシェフ多項式の最小 2 乗法、多数決とソフト投票、単体への射影と射影勾配法、5 分割の out-of-fold スタッキング、ソフトマックスのゲートの専門家の混合、マージンを記録するブースティング、正則化つきの利得の 2 次の勾配ブースティング、ランダム化した木と Extra Trees、c(n) の補正つきの Isolation Forest、重み付き多数決）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。乱数は p5.js 版と同じ種つきの mulberry32 で、引く順番もそろえてあるので、データ・学習の結果・自己テストの数値は p5.js 版と同じになります。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series64/

## 使い方

```
cabal run s64-00
```

番号を変えると別のスケッチが動きます（`s64-01`、`s64-15` など）。どのスケッチも一番下に「アンサンブル学習の道具」（種つきの乱数、k 近傍法・ロジスティック回帰・ナイーブベイズ・ニューラルネット・切り株、グラフ、自己テストなど）が入っています。学習や木を育てる計算は 1 フレームに数ミリ秒ずつ進めるので、画面は止まりません。スライダーのあるスケッチ（00・01・03）はマウスでドラッグします。色：クラス 0 = 金、クラス 1 = 青緑。記号は画面では ASCII で書きます（σ → `sigma`、ρ → `rho`、λ → `lambda`、γ → `gamma`、ε → `eps`、² → `^2`）。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や数学記号を出せないので、説明は短い英語で、記号は ASCII で書きます（上の「使い方」の対応）。グラフの目盛り・凡例・表の 11〜13 px の文字は 14 px にし、はみ出さないように説明を短くしたり、グラフの幅を少し狭くしたりしています。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 86 項目）。項目の名前と中に入る数値も p5.js 版と同じです（例：06 の out-of-fold 83.1% と 1 つだけのベスト 80.4%、08 の最小マージン 0.001 → 0.032 → 0.049 → 0.059）。結果は端末に出し、画面右下にも `Self-test OK 6 / 6` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、乱数の列を 1 本だけ持って引く順番もそろえた（乱数を順に引く小さなモナド `R`）ので、データ・ブートストラップ・初期値・シャッフルは p5.js 版と同じです。p5.js 版で自己テストのあとも同じ列から引き続ける所（01・03 のシミュレーション、15 の自動で教える点）は、自己テストの終わりの乱数の状態を `World` に入れて続けます。
- **1 フレームの計算時間**：p5.js 版の `performance.now()` で区切る計算（01・02・03・10・12）は、`sliced`（`GHC.Clock` で同じミリ秒の予算）で書き直しました。p5.js 版の `while` とちがい、1 フレームに最低 1 回は必ず動きます。
- **絵の作り直し**：p5.js 版が毎フレーム計算し直す値（02 のバイアス²・バリアンス、モデルの境界の絵など）は、データやモデルが変わったときに `World` に作っておき、毎コマは描くだけです。答えは同じです。
- **点線**：点線（0.5 の線、ρσ² の下限、バギングの平均など）は、短い線分を並べて描きます。03 の金の星は、へこんだ多角形を正しく塗るために中心からの三角形 10 枚で描きます。
- **04 ちがう種類のモデルの投票**：5 つのモデルの確率をマス目とテストの点で先に計算しておき、投票の絵と 31 通りの表はそこから作ります。ネットの学習中は 60 回ごとにネットの列だけを計算し直します（結果は p5.js 版の全部の計算し直しと同じ）。
- **06 スタッキング**：全部のデータで学習したモデルの、テストの点とマス目での予測はデータを作り直したときに 1 回だけ計算し、2 つのスタッキングで使い回します。
- **08 マージン**：訓練・テストの誤差と最小マージンの行は、画面に収まるように左下に置きます。残す累積分布の線のラベルは `r=5`、`r=20` などです。
- **09 2 次の勾配ブースティング**：木の図の箱は 2 行（`x<=0.42` と利得、葉は w）にして、14 px の文字が入るようにしました。
- **11 多様性の測り方**：英語の行の名前が入るように、7 × 7 の表を少し右（x = 250）に、マスを少し小さく（最大 60 px）しました。
- **12 Isolation Forest**：点ごとの異常スコアと順位は森を作り直したときだけ計算します（値は同じ）。マウスの位置の説明は 3 行に分けます。
- **13 自信のなさ**：±2σ の帯と σ(x) の面は、小さな四角形を並べて描きます。
- **14 アンサンブルの合唱**：Web Audio の鳴りっぱなしの 5 声 + 低音の代わりに、Art.Sound の `playTone` で 0.36 秒の短い音を 0.4 秒ごとに鳴らします（1 回 6 音で、同時に鳴らせる 8 音以内）。音量は p5.js 版と同じ `master`（0.1）× 声ごとの音量です。ソフト投票の地図と境界の白い線は 1 枚の絵にまとめます。歌い手の名前は短く（k-NN、logit、NB、net、stump）、F♯ は `F#` と書きます。
- **15 カメラ**：カメラは Art.Device（ffmpeg 経由、左右反転）で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像になります。1 フレームの画素数を抑えるため、6 つの検出器の小さな絵は半分の解像度（80 × 60）で作ります（映像と結果の絵は 160 × 120 のまま）。明るさと覚えた背景は p5.js 版の `Float32Array` と同じく 32 ビットの `Float` で持つので、結果も同じです。`S` の保存は PNG ではなく SVG です。
