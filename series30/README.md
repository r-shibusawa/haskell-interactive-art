# シリーズ30：オペレーションズ・リサーチ ─ Haskell コード集

限られた資源・時間・お金で「一番よい決め方」を探すオペレーションズ・リサーチのコード集 16 本を、Haskell（gloss）に移植しました。生産計画の線形計画法、整数計画と分枝限定法、輸送・スケジューリング・プロジェクト管理、在庫と不確かな需要、巡回セールスマンとメタヒューリスティクス、施設配置と配送計画、ゲーム理論までを、動かしながら体験します。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series30/

## 使い方

```sh
cabal run s30-00
```

番号を変えると別のスケッチが動きます（`s30-08`、`s30-14` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 📷 カメラは `ffmpeg` で読みます。使えないときはデモ映像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は短い英語です。記号も ASCII にしたので、03 の運賃は ¥ ではなく $ で表示し、≤ は `<=` と書きます。
- **文字の大きさ**：小さい文字を読みやすくするため 14 以上にそろえました。入りきらないところは次のようにしています。
  - 02：木の節の座標は、節が混み合うと小数 1 桁に減らし、さらに混むと省きます。
  - 04：幅のせまいバーには J1 などの名前を書きません。ヒストグラムの目盛りも間引きます。
- **図形**：角丸の長方形は普通の長方形です。
- **14 の音**：Web Audio の代わりに、波形のファイルを再生コマンドで鳴らします。発音まで少し遅れ、同時に 8 音までです。
  - 連続音は 0.2 秒おきの短い音のくり返しです。高さと大きさは毎回計算し直します。
  - カチッはノイズではなく短い高い矩形波で、1 秒に 10 回までです（p5.js 版は 30 回まで）。
  - コンプレッサーとフィルタはありません。
- **15 のカメラ**：
  - カメラがないとき、p5.js 版はマウスの跡だけをお客さんにしますが、こちらはデモ映像の明るい所とマウスの跡の両方を使います。デモ映像をクリックして色を追うこともできます。
  - 本物のカメラで点が 3 つ未満のときは、p5.js 版と同じくマウスの跡を使います。
  - 映像を薄く見せる tint は、背景色と混ぜて再現しています。
