# シリーズ52：心理物理学 ─ Haskell コード集

「どれだけ変われば、違いに気づく？」「2 倍の明るさは、2 倍に見える？」― 感覚の大きさを数で測るのが心理物理学です。ウェーバー・フェヒナー・スティーヴンスの法則から、恒常法・上下法・信号検出理論・強制選択という測り方、コントラスト感度・色の弁別・反応時間（ヒックとフィッツ）、等ラウドネス・音の高さ・マスキング、音と光の同時性まで、**自分が観察者になる実験**をして、自分のデータに関数を本当に当てはめるコード集です。00〜14 は O キーで「シミュレーション観察者」（本当の値がわかっているコンピュータの観察者）が答えます。p5.js 版と同じ計算（ロジスティック関数の最尤法、二分法で解く z、最小二乗法、上下法、同じ種の乱数）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series52/

## 使い方

```
cabal run s52-00
```

番号を変えると別のスケッチが動きます（`s52-01`、`s52-15` など）。どのスケッチも一番下に「心理物理の道具」（乱数・正規分布・上下法・直線の当てはめ・グラフ・自己テストなど）が入っています。🔊 音を使うスケッチ（11〜14）は Art.Sound で鳴らします。**音量は小さめから**（ヘッドホンは特に注意）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。光は 1 試行に 1 回だけで、速い点滅（3 Hz 以上）はありません。測った値は画面や部屋、端末・ヘッドホンによって変わります。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です（d′ は `d'`、Δ は `Delta`、Δf/f は `Df/f`、± は `+-`）。長い説明は 2 行に分け、グラフの位置を少し変えています。箱の角は丸くありません。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差で照合します（全部で 103 項目）。結果は端末に出し、画面左下にも `Self-test OK 6 / 6` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけ）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、引く順番もそろえたので、種を決めた計算（シミュレーション観察者・自己テスト・05 と 06 のノイズ・07 の上下法のパッチ）は p5.js 版と同じ数になります。種なしの試行は `Date.now()` の代わりに `randomRIO` で種を決めます。
- **時間**：刺激を見せる時間や間隔は `envTime`（フレームごとに進む）で測るので、1/60 秒きざみになります。
- **09 ヒック・10 フィッツの反応時間**：`envTime` は 1 フレーム（約 17 ms）ごとにしか進まないので、反応時間・移動時間は約 17 ms きざみで、少し短めに出ることがあります。光った時刻もフレームの描画時刻です（p5.js 版は 1 ms 未満の `performance.now()`）。画面の表示とキー入力の遅れも環境によって違うので、ブラウザ版とは数十 ms ずれることがあります。
- **02 スティーヴンス**：数字キー・小数点・Backspace・Enter で入力します（テンキーの Enter も可）。
- **04 上下法**：刺激は p5.js 版と同じく画面の全画素（537×260）で乱数を引いてディザをかけますが、画像にするのは点のまわり 61×61 だけで、その外は背景と同じ値です。
- **05・06 ノイズ刺激**：試行ごとに 1 回だけ作り（画素値まで p5.js 版と同じ）、灰色のピクセル画像を拡大して描きます。05 の得点表の名前は英語（Neutral / Don't miss / No false alarms）です。
- **07 コントラスト感度**：キャンベル-ロブソン型の図は 8 万画素以下にするため、横は 1 画素ずつ、たては 120 段で作って引き伸ばします（そのためこの図のディザの乱数は p5.js 版と同じ列ではありません）。クリックの位置と周波数・コントラストの対応は p5.js 版と同じです。07・08 の図の大きさは起動時の画面で決まります。
- **08 色の弁別**：基準の色の名前は英語（gray / reddish skin / green / blue / yellow）です。
- **11〜14 の音**：Web Audio の代わりに Art.Sound の `playTone`（正弦波）で鳴らします。全体の音量 `master` = 0.15 は p5.js 版と同じ。最初のクリックは要りません。2 つ目の音・光・音の組は `envTime` で予約して鳴らします。Art.Sound の音は鳴っている間に少しずつ小さくなります（p5.js 版は平らで両端 15 ms だけなめらか）。11 の基準音と比べる音は同じ形です。
- **小さな音量**：Art.Sound は音を「0.01 刻みに丸めた音量」の WAV で使い回すので、音量の段ごとに周波数へ 0.01 Hz の聞こえない差をつけて別の WAV にしています。小さい音量も丸めずにそのまま鳴ります。
- **13 マスキング**：Art.Sound には雑音がないので、帯域フィルタを通したノイズの代わりに、帯域 1000 ± BW/2 にランダムに置いた 6 つの正弦波を鳴らします（全体のパワーは p5.js 版と同じく BW に比例）。音色は「ザー」より和音に近く、マスキングの量は本物のノイズと少し違います。
- **14 音と光の同時性**：光はフレーム（約 17 ms）単位、音は再生コマンド（afplay）の起動の遅れ（数十 ms）のぶん遅れて出るので、PSS は + 側（音が遅れた側）にずれます。p5.js 版の `outputLatency` 補正の代わりに ★ `audioLead`（初期値 0 秒）で音を早めに鳴らせます。
- **15 カメラ**：カメラは ffmpeg 経由で 160×120 で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像（計算結果も同じ）になります。`S` の保存は PNG ではなく SVG です。
