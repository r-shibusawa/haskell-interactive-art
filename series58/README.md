# シリーズ58：クリフォード代数 ─ Haskell コード集

「ベクトルどうしの掛け算って何？」― 内積と外積をひとつにまとめた**幾何積**から、回転・反射・面積・体積・交わりを 1 つの代数（**幾何代数**）で計算するコード集です。ウェッジ積と二重ベクトル（向き付きの面）、2 次元の I² = −1 と複素数、鏡の反射 −n v n⁻¹ と 2 回の反射でできるローター、3 次元の回転と四元数、行列式とクラメルの公式、双対と交わり、符号 (p, q) で変わる代数、時空の代数のローレンツブースト、円を外積 1 つで表す共形幾何代数、角運動量 L = r∧p まで、どれも**本当に計算した**マルチベクトルで動いています。p5.js 版と同じ計算（ビットマスクで番号をつけた基底、並べかえの回数の符号と e_i² で決まる掛け算表、n = 5・32 成分まで同じコード）を Haskell（gloss）で書き直し、マルチベクトルは 2ⁿ 個の `Double` を並べた unboxed vector で表しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series58/

## 使い方

```
cabal run s58-00
```

番号を変えると別のスケッチが動きます（`s58-01`、`s58-15` など）。どのスケッチも一番下に「幾何代数の道具」（`makeAlgebra` で作る代数、幾何積 `gp`・外積 `wedge`・左縮約 `lc`・逆順 `rev`・双対 `dualOf`・交わり `meet`・二重ベクトルの指数関数 `expB`、比べるための行列や外積、種つき乱数、自己テストなど）が入っています。16 本とも同じ道具です。基底の番号は p5.js 版と同じビットマスク（n = 3 なら 0 = 1、1 = e1、2 = e2、3 = e12、4 = e3、5 = e13、6 = e23、7 = e123）。06・07・09 は 3D で、ドラッグで視点を回し、ホイールで近づけます。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。記号は ASCII で書きます（∧ は `^`、⌋ は `_|`、∨ は `v`、a⁻¹ は `a^-1`、R̃ は `R~`、⟨M⟩k は `<M>k`、θ・φ・α は `theta`・`phi`・`alpha`、° は `deg`、e∞ は `einf`、½ は `1/2`、− は `-`）。基底の名前も ASCII で、11 の γ0・γ1 は `g0`・`g1`、12 の e₊・e₋ は `ep`・`em`（例：`e12p`）です。英語の説明が長くなるので、00・03・05・11 などの一部の行は 2 行に分けたり、少しちがう場所に書いたりしています。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（16 本で全部 111 項目。00 から順に 7・8・8・7・7・6・7・7・6・6・7・8・8・6・6・7）。結果は端末に出し、画面右下にも `Self-test OK 7 / 7` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：自己テストの `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、引く順番もそろえたので、乱数の列は p5.js 版と同じです。02・08 のスペース（ランダムな値）は `Math.random()` の代わりに `randomRIO` を使います。
- **3D（06・07・09）**：WEBGL と orbitControl の代わりに、自分で回すカメラ（ドラッグで方位角と仰角、ホイールで距離）で透視投影し、線や面を奥から順に描きます（画家のアルゴリズム）。最初の視点は p5.js 版の `camera(...)` と同じ位置です。半透明の平面は小さな四角に分けて並べ、07 の白い点・09 の白い球は円で描きます。回す速さは orbitControl と少しちがいます。HTML で重ねていた文字は左上の文字になり、07 の四元数の掛け算表はますごとに並べます。
- **塗りつぶし**：gloss はへこんだ多角形を塗れないので、04 の「F」は三角形に分けて、05 の回す図形と 13 の扇形は最初の点から扇のように塗ります。点線は短い線を並べて描きます。
- **10 符号**：n = 4（16 × 16 の表）では、名前が入るようにますを横長にし、表の文字を 12 px にしています。
- **14 幾何代数の音**：Web Audio の 4 つの持続音の代わりに、Art.Sound の `playTone` で 4 つの声部（スカラーは正弦波、ほかは三角波）を 0.3 秒ごとに短く鳴らします。音量は 次数の大きさの割合 × `master`（0.12）で、ローパスフィルタはありません。最初のクリックかキーで音が始まります。擬スカラーの声部の名前は `trivector` と書きます。
- **15 カメラの万華鏡**：カメラは ffmpeg 経由で読みます（左右反転ずみの映像）。canvas の clip と変換の代わりに、画面を 1/5 の大きさ（1 画素 = 5 × 5）に分け、画素ごとに各像の行列で逆にもどして種のすき間に入るかを調べ、映像のどの点を映すかの表を作ります（鏡が変わったときだけ作り直す）。閉じないときは p5.js 版と同じく 0.45 の透明度で重ねます。カメラが無いか V で切ると、p5.js 版と同じ考えのテスト画像（色の帯・円・「GA」の文字。文字はドットで描く）になります。`S` の保存は PNG ではなく SVG です。
- **13 の数の書き方**：「ゆれ幅」は `4.4e-16` のような書き方で、0 は `0.0e0` と出ます（p5.js 版は `0.0e+0`）。
