# シリーズ12：動的計画法・貪欲法・償却解析 ─ Haskell コード集

小さな答えを表に貯めて大きな答えをつくる「動的計画法（DP）」、その場で一番よいものを選び続ける「貪欲法」、たまに高くつく操作を平均でならす「償却解析」。アルゴリズム設計の 3 つの道具を、表が 1 マスずつ埋まっていくアニメーションで体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結していて、表の計算は遅延評価の配列や `Data.Map`、`Data.Vector.Unboxed` でそのまま書いてあります。

参考：Cormen ほか『Introduction to Algorithms』

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series12/

## 使い方

```sh
cabal run s12-00
```

番号を変えると別のスケッチが動きます（`s12-07`、`s12-14` など）。

- ほとんどのスケッチは **スペース = 再生・停止、→ = 1 手ずつ、R = 最初から** です。
- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。無ければ音なしで動きます。

## p5.js 版との違い

- 画面の文字は英語です（gloss の文字は ASCII のみ）。日本語の説明はソースのコメントにあります。
- 記号も ASCII に置きかえました。空文字 ε は `-`、空白 ␣ は `_`、Φ は `Phi`。03 の矢印は線で描き、10・11 の ¥ の貯金は金色の丸だけで示します。04 の操作名はマスの中では頭文字（m / r / i / d）で、意味は凡例にあります。
- 表やカードの角丸は、角を少し落とした四角です。
- 文字を 14 ピクセル以上にしたので、数字が入るように一部のマスを横長にしました（02 の表、07 の表）。00 のボトムアップで n が大きいと、マスを縦長にして数字を縦書きにし、見出しは番号だけになります。
- 04：Esc では編集を終われません（gloss では Esc でウィンドウが閉じます）。Enter か、単語の外をクリックして決定します。入力中は 1 文字ごとに表を作り直します。
- 13：音は Web Audio の予約ではなく、時刻が来たら 1 音ずつ外部コマンドで鳴らすので、少し遅れることがあります。
- 14：ノイズは p5.js の `noise` と別の実装なので、同じ式でも山の模様は少し違います。`noiseSeed` の代わりにノイズの座標を乱数でずらしています。守る・消すの色は、1 マスずつ四角を重ねる代わりにピクセル画像の色に混ぜています。キャンバスのクリックで音を許可する操作はなく、音はそのまま鳴ります（同時に鳴らせるのは 8 音までなので、自動で速く削るときは鳴らない音があります）。
