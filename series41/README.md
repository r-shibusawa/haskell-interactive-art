# シリーズ41：組合せ論 ─ Haskell コード集

「何通りあるか」を目で見て数える。順列・組合せ・二項係数から、パスカルの三角形と母関数、鳩の巣原理・包除原理・カタラン数・整数分割、ラムゼー理論やラテン方格までを、小さい場合をすべて列挙してアニメーションで確かめるコード集です。p5.js 版と同じ計算を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series41/

## 使い方

```
cabal run s41-00
```

番号を変えると別のスケッチが動きます（`s41-01`、`s41-15` など）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。文字は 14 より小さくしません。長い説明は行を分け、英語が入るように右パネルを少し左に寄せたスケッチがあります（01・02・07・10）。パネルやマスの角は丸くありません。記号は ASCII で書きます（★ は `*`、✓ は `OK`、ドレミ は `Do Re Mi`）。
- **03 パスカルの三角形**：丸に入らない大きな数は `..` と書きます（p5.js 版は文字を小さくしています）。三角形は説明の行と重ならないよう少し下げました。
- **04 母関数**：棒の幅に入らない数は 90 度回して、棒の中か上に書きます。
- **05 星と棒**：箱の幅も式の欄にかからないよう少し狭めました。
- **07 包除原理**：D_n の表は横に長いので、`n: D_n D_n/n!` の 2 列 4 行にしました。
- **08 カタラン数**：上の帯を説明の行と重ならない位置に下げ、経路の高さを帯の中に収めました。漸化式の説明は 2 行です。
- **09 整数分割**：一覧の列に入らない分割は `2^3`（2 が 3 個）の形にちぢめて書きます。
- **11 ラテン方格**：記号（●▲■◆★✚♥）は文字ではなく図形で描きます。
- **12 帽子問題**：帽子と人の名前は `H1`、`P1` と書きます。分布の数字は `.368` の形です。乱数は Fisher–Yates の計算ごとに世界の中の種から作ります。
- **13 順列を聴く**：短い音を 1 つずつ鳴らすので、発音までに少し遅れがあります。ローパスフィルタは使えないので、音色は転倒数で三角波とのこぎり波を切り替えるだけで、画面のフィルタの値も省きました。
- **14 パスカル・ブラシ**：紙に焼きつけるのではなく、描いたマスを新しい順に 7000 個まで覚えて毎フレーム描き直します。超えると古いものから消えます（`maxInk`）。`S` の保存は PNG ではなく SVG です。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。ffmpeg やカメラが無いときは、p5.js 版と同じく 4 秒後にノイズ画像へ切り替わります。C(k,r) の大きな数は `Integer` で計算し、長いので 2 行に分けて書きます。
