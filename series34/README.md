# シリーズ34：暗号理論 ─ Haskell コード集

秘密を守る数学を、自分の手で破って・つくって体験する。シーザー暗号の総当たりと頻度分析から、ワンタイムパッド、ブロック暗号と利用モード、ハッシュ、ディフィー＝ヘルマン、RSA、楕円曲線、デジタル署名、ゼロ知識証明、秘密分散まで、古典から現代の暗号までを小さな数で動かす 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

> ⚠️ すべて**教育用**です。鍵や素数をわざと小さくしてあるので、実際の安全な暗号には使わないでください。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series34/

## 使い方

```sh
cabal run s34-00
```

番号を変えると別のスケッチが動きます（`s34-07`、`s34-14` など）。

- 🔊 音を使うスケッチ（14）は `afplay`（macOS）または `aplay`（Linux）で鳴らします。実行したらまず画面を 1 回クリックするかキーを押します。
- 📷 カメラ（15）は `ffmpeg` で読みます。使えないときは動く絵を暗号化し、画面にそのことが表示されます。

## p5.js 版との違い

- 画面の文字は gloss のフォントの都合で英語（ASCII）です。⊕ は `xor`、φ は `phi`、✓✗ は `OK` / `(bad)` などと書きます。12 のグラフの「封」は `?` です。
- 文字が p5.js 版より幅をとるので、長い説明は複数行に分け、一部の配置を変えました（03・12 は重なりを避けるためパネルや洞窟を少し小さくしています）。
- 04 のローターの配線は同じ種（7）から作りますが、乱数の作り方が違うので p5.js 版とは別の配線です。
- 06 の画像 2 の「p5」は、画像の中に文字を描けないので棒と輪で組み立てた字です。また画素の縁のなめらかさ（アンチエイリアス）はありません。
- 10 の曲線・直線・点は左のパネルの外にはみ出さないように切っています。
- 14 の音は Art.Sound で鳴らすため、発音までに少し遅れがあります。
- 07 のビット列の横に出す文は、幅の都合で先頭 36 文字までです（ハッシュの計算には全文を使います）。
- 15 のカメラなしのときの絵の「HELLO」はドット絵です。鍵を変えたときの表の計算を速くするため、S ボックスと P ボックスも表にしています。

すべて教育用の小さなモデルです。考え方は本物（AES・SHA-256・RSA・ECDH・シャミア）と同じですが、鍵が小さいのですぐ破れます。
