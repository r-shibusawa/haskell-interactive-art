# シリーズ44：流体力学 ─ Haskell コード集

水や空気の「流れ」を自分の手で動かす。流線の見方から、連続の式・ベルヌーイの定理、ポテンシャル流と翼の揚力、そして粘性と**ナヴィエ・ストークス方程式**を実際に数値で解いて、渦・乱流・波までを体験するコード集です。p5.js 版と同じ計算を Haskell（gloss）で書き直しています。格子の上のソルバーは、書きかえのできる配列（`Data.Vector.Unboxed.Mutable`）と `ST` で、p5.js 版と同じ順番に計算します。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series44/

## 使い方

```
cabal run s44-00
```

番号を変えると別のスケッチが動きます（`s44-07`、`s44-15` など）。

## ナヴィエ・ストークス方程式

このシリーズの中心になる式です（非圧縮性の流体）。

```
∂u/∂t + (u·∇)u = −(1/ρ)∇p + ν∇²u + f ,　　∇·u = 0
        └ 移流 ┘   └ 圧力 ┘   └ 粘性 ┘  └ 外力     └ 非圧縮（連続の式）
```

画面には ASCII で `du/dt + (u.grad)u = -grad p/rho + nu lap u + f ,  div u = 0` と書いてあります。07 では格子の上で「① 外力 → ② 粘性（拡散）→ ③ 移流 → ④ 圧力（射影）」の順に本当に解き、各項を 1〜4 キーで ON/OFF できます（Stam の Stable Fluids）。08・13・14・15 は同じソルバー、10 は渦度・流れ関数の形、09 は格子ボルツマン法（マクロにはナヴィエ・ストークス方程式にしたがう）で解いています。

## p5.js 版との違い

- **格子の大きさと反復の回数**：すべて p5.js 版と同じです（07 は 128 × 80、08・09・12・14 は 160 × 100、13・15 は 112 × 70、10 は 65 × 65、反復の回数も同じ）。縦の格子の数は p5.js 版では画面の形から計算しますが、ここでは 1280 × 800 の画面に合わせた数に固定しています。
- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。式は ASCII で書きます（∂u/∂t は `du/dt`、∇ は `grad`、∇² は `lap`、∇· は `div`、ω は `w`、ρ・ν・Γ は `rho`・`nu`・`Gamma`）。03 の部品の印は `+`（湧き出し）`-`（吸い込み）`R`（時計回りの渦）`L`（反時計回りの渦）`D`（二重極）、11 の渦の印は `+` と `-` です。
- **等高線（03・04・05・10）**：マーチングスクエア法で求めた小さな線分を、端どうしをつないで折れ線にまとめてから描きます（線分のまま描くと数が多すぎて遅いため）。線の形は同じです。
- **ガウス・ザイデル法（07・08・10・13・14・15）**：計算の中身は同じですが、速くするために足し算の順番を並べかえています（左どなりの新しい値を最後に足す）。丸め誤差の程度の差しかありません。
- **08 ノズルのゆれ**：`Math.random()` の代わりに、フレーム番号と場所から決まる疑似乱数を使います。
- **11 軌跡**：p5.js 版は前のフレームの上に半透明の背景を重ねて尾を残します。gloss は毎フレーム描き直すので、画面の 1/4 の大きさの色の配列に粒と渦を書きこみ、毎フレーム背景色へ 14% ずつ近づけて、4 倍に拡大して表示します。
- **13 音**：音は Art.Sound で鳴らすので、少し遅れて鳴ります。左右の定位（パン）はありません。続く音（ドローン）は、0.5 秒ごとに鳴らし直す短い三角波の連なりです（p5.js 版はローパスをかけたのこぎり波）。音を出す許可のための最初のクリックはいりません。
- **14 保存**：S は画面（文字なし）を SVG で保存します（p5.js 版は PNG）。
- **15 カメラ**：映像と染料は格子と同じ 112 × 70 の大きさで重ねて表示します。カメラが使えないときはマウスでかき混ぜます（p5.js 版と同じ）。
