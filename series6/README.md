# シリーズ6：通信理論 ─ Haskell コード集

0 と 1 を、遠くへ、正しく、速く届けるには？ 文字とビット、エントロピー、AM / FM とデジタル変調、雑音と誤り訂正、圧縮、暗号、シャノンの定理、CDMA、周波数ホッピングまでを体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series6/

## 使い方

```sh
cabal run s6-00
```

番号を変えると別のスケッチが動きます（`s6-07`、`s6-12` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 🎤 マイクは `ffmpeg` で読みます。使えないときはデモの信号で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。長い説明は短くするか、複数行に分けています。空白は `_`、⊕ は `^`、・ と ー は `.` と `-` で表します。
- **音**：Web Audio の代わりに、波形のファイルを再生コマンドで鳴らします。発音まで少し遅れ、同時に 8 音までです。
  - 02 の音は連続音ではなく、0.1 秒ごとの短い音のくり返しです。音量または周波数を、その時点のメッセージの値で変えます。
- **10 のスペクトル**：ブラウザの AnalyserNode の代わりに、鳴らしている音と同じ 2 つの正弦波をプログラムの中で作って計算します。手順（ブラックマン窓、約 85 ms、なめらかさ 0.8、-100〜-30 dB）は同じですが、スピーカーから出た実際の音を調べているわけではありません。
- **11 のマイク**：マイクが使えないとき、p5.js 版は音量 0 のままですが、こちらはデモの信号で動きます。
- **08**
  - 1〜3 はお手本の切りかえ専用です（文章に数字の 1〜3 は打てません）。
  - 木の描き方を変えました。p5.js 版は階層ごとに枝の幅を半分にしますが、こちらは葉を左から等間隔に並べて、文字が重ならないようにしています。深い木は段の間隔も縮めて画面に収めます。枝の丸は回数の文字が入るように少し大きくしています。
  - 圧縮後のビット数は、表が画面に入りきらないときも全部の文字で数えます（p5.js 版は表示できた分だけを数えます）。
- **09**
  - p5.js 版のハートは画面では上下逆になるので、正しい向きに直しました。
  - 3 枚の絵を 1 枚のピクセル画像で描くので、マスの間の細いすきまはありません。
- **配置の調整**：大きくなった文字が重ならないように、次の配置を変えています。
  - 01：コインの間隔をウィンドウに収まるように縮めます。
  - 04・13：右側の表示の位置や折り返しを変えています。
  - 06：検査結果を受信の行の右に出します。
  - 07：凡例をグラフの右下に移し、画面外にはみ出す `p=10^0` の目盛りを省きます。
  - 10：周波数の目盛りを 2 段に分けます。
  - 12：パケットの札と送信・受信の丸を少し大きくし、受信した文字の間に空白を入れます。
  - 15：妨害電波の文字に下地をつけて、パケットの上に出します。
