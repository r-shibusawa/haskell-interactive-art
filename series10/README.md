# シリーズ10：ソートと計算量 ─ Haskell コード集

参考：Cormen ほか『Introduction to Algorithms』

アルゴリズムの「速さ」を目で見て、耳で聞く。挿入ソート・マージソートから、分割統治、乱択、ヒープ、クイックソート、比較しないソート、選択問題までを体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series10/

## 使い方

```sh
cabal run s10-00
```

番号を変えると別のスケッチが動きます（`s10-07`、`s10-13` など）。

- 多くのスケッチは **スペースで再生／停止、→ で 1 手ずつ、↑↓ で速さ** です。
- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 配列の添字は p5.js 版に合わせて **0 始まり** です。
- 画面の文字は英語です。Space はスペース、Right / Left / Up / Down は矢印キーのことです。

## p5.js 版との違い

- **1 手ずつ止まるしくみ**：JavaScript のジェネレーター（`function*` と `yield`）の代わりに、各スケッチの下にある小さな `Gen` を使います。アルゴリズムの書き方は同じで、結果は「状態の遅延リスト」になります。配列は 1 手ごとに新しく作ります（要素数が小さいので速さは問題になりません）。
- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。Θ や n² などの記号は Theta、n^2 と書きます。読みやすさのために文字は 14 以上にしたので、いくつかの見出しは短くしました（01 の深さは d0、d1 …）。
- **棒の角**：棒やマスの角は丸くなりません。
- **02**：マウスの点線は短い線を並べて描きます。
- **04**：見せきれない小さな積の個数は「…ほか N 個」ではなく、段の見出しに「(300 shown)」と書きます。
- **08**：再帰の深さの帯は、画面からはみ出さないよう、深くなると間隔をつめます。
- **09**：n = 4 の葉の文字は長いので、木を少し上につめて、はみ出さないようにしました。
- **12**：3 の比較回数は、組の中を挿入ソートで並べたときの回数です。p5.js 版はブラウザの `sort` が比べた回数を数えるので、少しちがう数になります。
- **13**：音は波形のファイルを再生コマンドで鳴らすので、発音まで少し遅れ、同時に 8 音までです。速さを上げると鳴らない音が出ます。完成の演出は、全部を同時に予約する代わりに、4 個おきの音を順に鳴らします。音を出すための最初のクリックは不要ですが、クリックで再生が始まるのは同じです。
- **14・15**：棒が見出しに重ならないよう、14 のモード 2・3 は棒の高さに上限があります。15 のヒストグラムの目盛りは、重ならない間隔で間引きます。
