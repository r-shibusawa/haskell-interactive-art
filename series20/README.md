# シリーズ20：制御工学 ─ Haskell コード集

「測って・比べて・直す」。フィードバック制御の考え方を、台車・タンク・倒立振子・ドローンを動かしながら体験するコード集です。開ループと閉ループ、一次遅れ・二次系、極と安定性、P・PI・PID 制御、ボード線図・根軌跡・ナイキスト線図、状態空間と極配置、オブザーバーとカルマンフィルタ、音や声を使った制御までを、Haskell（gloss）で動かします。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series20/

## 使い方

```
cabal run s20-00
```

番号を変えると別のスケッチ（`s20-01`、`s20-15` など）が動きます。

## p5.js 版との違い

- 画面の文字は英語です（gloss の文字は ASCII のみ）。τ は tau、ζ は zeta、ω は w と書き、長い説明は短くして数行に分けました。小さい文字は 14 にそろえました。
- 角丸の四角は普通の四角です。
- 03：s 平面の同心円は枠の中だけ描きます（p5.js 版は枠の外まではみ出します）。
- 03・07：インパルス応答とボード線図のデータは、毎フレームではなく極やシステムが変わったときだけ計算します（結果は同じ）。
- 08・09・11：根の計算、数値微分、逆行列は桁が必要なので Double で計算します。
- 09：ナイキスト曲線は枠で切り取ります。GM・PM の印は枠の端までで止め、向きの印は枠の外なら描きません。
- 12：測定 z と差分の線は半透明の白です（ノイズの線で題名やほかの線が隠れないように）。
- 13：音は Art.Sound で鳴らします。連続音の代わりに短い音（0.22 秒）を 0.2 秒ごとに鳴らすので、音の高さは階段状に変わり、発音まで少し遅れます。音量も `noteVol`・`targetVol` で別に決めています。
- 14：マイクは ffmpeg で読みます（`Art.Device`）。波形は 1024 点ではなく 512 点（22050 Hz）で音量を計算します。ffmpeg やマイクがないときは p5.js 版と同じくマウスの高さが目標です。
- 15：S の保存は PNG ではなく SVG です。軌跡は消えない絵の層ではなく線分の履歴で、最大 3000 本（★ `trailMax`）です。ほとんど動いていないときは足さないので、同じ場所を重ねても濃くなりません。風のノイズは `noise2` を使うので、変化のしかたは p5.js の `noise` と同じではありません。
