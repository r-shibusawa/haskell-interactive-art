# シリーズ39：射影幾何学 ─ Haskell コード集

「平行線は無限遠で交わる」。透視図法の消失点から出発して、同次座標・外積・ホモグラフィ・複比、デザルグ／パップス／パスカルの古典定理、有限射影平面、ピンホールカメラまでを、自分の手で動かして体験するコード集です。p5.js 版と同じ計算を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series39/

## 使い方

```
cabal run s39-00
```

番号を変えると別のスケッチが動きます（`s39-01`、`s39-15` など）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。∩ は `^`、∞ は `inf`、× は `x` と書きます。パネルの角は丸くありません。行列の数値は等幅フォントの代わりに列をそろえて並べています。
- **座標**：どのスケッチも `view` という道具で p5.js と同じ座標（左上が原点、y は下向き）に置いて描きます。
- **数値**：同次座標の計算は Double です（行列式 ≈ 0 を見るため）。画面の座標は Float です。
- **無限遠点の矢印**：上の説明文と下の文字にかからないよう、矢印は画面のふちより少し内側（上は 90 px より下、下は 30 px より上）の枠の中に置きます。
- **01 同次座標**：平面の格子と断面図の直線は、それぞれの枠の中だけに描きます（p5.js 版は枠の外にもはみ出します）。スケール倍の 3 組は横に並ばないので縦に並べました。←→ は押し続けると w が動き続けます。
- **05 円錐曲線**：点線は短い線分を並べて描きます。
- **12 カメラ**：WebGL の深度バッファの代わりに、線を奥行きで並べて奥から描きます（画家のアルゴリズム）。カメラと画像面が右のパネルに隠れないよう、世界の図は画面の左寄りに置きます。行列のパネルは読みやすいようにほぼ不透明です。
- **13 複比を聴く**：音は起動してすぐ出るので、最初のクリックは要りません。H の鳴らしっぱなしの音の代わりに、0.3 秒ごとに短い音をくり返します（`humPeriod` で変更可）。ドラッグ中の音程はなめらかには変わらず、発音までに少し遅れがあります。
- **14 透視図法ブラシ**：線は合計 1800 点まで覚えて毎フレーム描き直します。超えると古い線から消えます（`maxInk`）。`S` の保存は PNG ではなく SVG です。←→ は押し続けると回り続けます。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。ffmpeg やカメラが無いときは p5.js 版と同じチェッカーになります。出力は 1 枚 8 万画素以内に収めるため、少し小さくしました（A4 236×334、正方形 280×280、横長 342×228。p5.js 版は 240×340、300×300、360×240）。
