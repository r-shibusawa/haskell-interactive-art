# シリーズ46：群知能 ─ Haskell コード集

1 匹 1 匹は単純なルールで、となりとやりとりするだけ。それなのに群れ全体は渦を巻き、リズムをそろえ、最短路や良い答えを見つけ、巣の場所まで決める。群れの動き・群れによる最適化（ACO・PSO・人工蜂・ホタル）・スティグマジー（環境を介した協調）・集団の意思決定を、本物のアルゴリズムを動かして体験するコード集です。p5.js 版と同じモデル・同じ数値（パラメータ、乱数の使い方、収束のグラフ）を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series46/

## 使い方

```
cabal run s46-00
```

番号を変えると別のスケッチが動きます（`s46-01`、`s46-15` など）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。文字は 14 より小さくしません。記号は ASCII で書きます（φ は `phi`、η は `eta`、ε は `eps`、λ2 は `l2`、² は `^2`）。
- **乱数**：`Math.random()` の代わりに、World の中に入れた乱数の種（xorshift）から作ります。種は起動のたびに変わり、R でやり直すと別の乱数で始まります。
- **04〜07 の計算の精度**：フェロモンの表、関数の値、粒子・エサ場・ホタルの位置は Double（JavaScript と同じ 64 ビット）で計算し、描くときだけ Float にします。05・06・07 の等高線は p5.js 版と同じ 220 × 220 の画像で、関数を変えたときだけ作り直します。
- **08 シロアリの柱づくり**：一番重い設定（1500 匹 × 1 フレーム 60 歩）では 1 フレームに 15〜30 ms かかり、60 fps を保てません（p5.js 版と同じく、重いときは ← で速さを下げます）。最初の設定（500 匹 × 20 歩）は軽く動きます。
- **08・09・11 の格子**：土・卵・踏み跡の格子は p5.js 版と同じ大きさで、ピクセル画像を拡大して描きます。08・09 はシロアリ・アリを 1 匹ずつ順番に動かし、格子をその場で書きかえます（p5.js 版と同じ順序）。
- **10 道の分岐と最短路**：半透明の太い線を重ねると継ぎ目が濃くなるので、橋の色は背景と混ぜた不透明な色で描きます（混ぜる割合は p5.js 版の透明度と同じ）。
- **11 歩くほど道になる**：人は踏み跡 V（3 フレームごとに更新）だけを見て歩くので、全員の 1 歩を先に計算してから、踏んだマスを同じ順番で踏み固めます。結果は p5.js 版の 1 人ずつの処理と同じです。
- **13 合意と多数決**：グラフ名などの数値の欄は、右の狭い欄に収まるよう短い英語にしています（「理論」の式はグラフの下の 1 行）。
- **14 群れの音楽**：音は OS の再生コマンドで鳴らすので、最初のクリックは不要です（クリックしても何も起きません）。発音までに少し遅れがあります。アルペジオの「0.06 秒ずつずらす」は、鳴らす予定の音を World に入れておき、その時刻のフレームで鳴らします。同時に鳴る音は 8 音までです。
- **15 カメラの光に集まる群れ**：通った跡は画面の 1/4 の解像度（320 × 200）の画像に塗り重ねて、引き伸ばして表示します（p5.js 版は画面と同じ大きさの線）。そのため跡は少し太く、かくかくして見えます。F の「跡を消していく」は毎フレーム紙の色を 4 % 重ねます。全員を同時に動かします（p5.js 版は 1 匹ずつ順に動かし、次の 1 匹はその新しい位置を見ます）。`S` の保存は PNG ではなく SVG です。カメラは ffmpeg 経由で読み、使えないときは p5.js 版と同じくマウスの周りがエサになります。
