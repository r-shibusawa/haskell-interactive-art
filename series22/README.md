# シリーズ22：ボロノイ図 ─ Haskell コード集

「いちばん近いのはどれ？」で平面を塗り分ける。ボロノイ図の作り方（垂直二等分線・ドロネー三角形分割・掃引線）、ロイドの緩和と点描画、重みつきボロノイ、最大空円と経路計画、自然の模様、音とカメラまでを、Haskell（gloss）で体験するコード集です。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series22/

## 使い方

```
cabal run s22-00
```

番号を変えると別のスケッチ（`s22-01`、`s22-15` など）が動きます。

## p5.js 版との違い

- 画面の文字は英語です（gloss の文字は ASCII のみ）。長い説明は短くして、2〜3 行に分けました。
- 配置は 1280×800 の窓に合わせた固定の大きさです。窓を広げても絵は中央に同じ大きさで出ます。
- 角丸の四角（06・09 のパネルや 09 の店）は普通の四角です。
- 07：絵 3 の文字「p5」「VORONOI」は、フォントを画素に描けないので、折れ線で書いた文字を太くして作っています（字の形が少し違います）。V の元の絵は 4 画素まとめて、背景の色と混ぜて表示します。
- 08：ホイールは 1 目盛りで重みが 5 変わります。
- 11：面積の帯は 640×70 の画像を 2 倍にして表示し、2 フレームに 1 列ずつ描き足します（流れる速さは同じで、細かさが半分です）。
- 13・14：音は Art.Sound で鳴らします。発音まで少し遅れ、同時に鳴るのは 8 音までです。「最初のクリックで音をスタート」は p5.js 版と同じにしてあります。
- 14：S の保存は PNG ではなく SVG です。太い枠の角は丸くなりません。
- 15：カメラは ffmpeg で読みます（`Art.Device`）。カメラがないときの代わりの絵は、丸と縞の絵ではなく `Art.Device` の動く合成映像です。
- 速さのための書きかえ（結果は同じ）：05 は各画素の最寄りのサイトをサイトが変わったときだけ計算し、02 は max(|dx|, |dy|) が今の最小以上のサイトで累乗を省きます。06・14 はセルに届かない二等分線を飛ばし、12 のダイクストラ法は優先度つきキュー（`Data.Set`）を使います。
- 外接円の計算は桁が大きいので Double で、多角形の面積と重心は Float の桁落ちを防ぐため最初の頂点からの相対座標で計算します。
