# シリーズ35：カタストロフィー理論 ─ Haskell コード集

原因はなめらかに変わるのに、結果が突然とぶ。ルネ・トムのカタストロフィー理論を、転がるボール・折りたたまれた曲面・ゴムひもの機械・光の網目・船の転覆・草原の崩壊で体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series35/

## 使い方

```sh
cabal run s35-00
```

番号を変えると別のスケッチが動きます（`s35-07`、`s35-14` など）。

- 🔊 音を使うスケッチ（13・14）は `afplay`（macOS）または `aplay`（Linux）で鳴らします。実行したらまず画面を 1 回クリックするかキーを押します。
- 📷 カメラ（15）は `ffmpeg` で読みます。使えないときはマウスで操作でき、画面にそのことが表示されます。

## p5.js 版との違い

- 画面の文字は英語です（gloss の文字は ASCII のみ）。パネルの角は丸くありません。
- 03：WEBGL の代わりに自前の投影と画家のアルゴリズムで描きます。布の格子は 50 × 160 から 26 × 72 に粗くし、面ごとの単色で、光は両面に当てています。奥行きは面の中心で比べるので、交わる所で前後が少し乱れることがあります。
- 09：加算合成（`blendMode(ADD)`）がないので、ふつうの半透明の重ね塗りです。光線が集まる所は白くとばず、線の色で頭打ちになります。
- 13・14：鳴りっぱなしの音の代わりに、短い音を約 1/6 秒ごとに鳴らします。音の高さはなめらかにすべらず、発音にも少し遅れがあります。
- 14：絵を画面に残せないので、線を最新 2500 本まで覚えて毎回描きます。それより古い線から消えます。`S` の保存は PNG ではなく SVG です。
- 15：カメラが使えないときの合成映像は追わず、p5.js 版と同じくマウスで操作します。
