# シリーズ48：錯視 ─ Haskell コード集

見えているもの ≠ そこにあるもの。同じ長さの線、同じ灰色、同じ大きさの円が、まわりの模様しだいで違って見える「錯視」を、プログラムで作って確かめるコード集です。長さ・大きさ・傾きの錯視、明るさと色の錯視、動きと残像、主観的輪郭と不可能図形、そして音とカメラまで。p5.js 版と同じ図・同じ数値を Haskell（gloss）で書き直しています。どのスケッチにも「真実を見る」（T キー）があり、比べている 2 つが本当に同じであることを確かめられます。調整法（心理物理学の測り方）で、自分の錯視の強さを数字で記録します。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series48/

## 使い方

```
cabal run s48-00
```

番号を変えると別のスケッチが動きます（`s48-01`、`s48-15` など）。どのスケッチも一番下に「錯視の道具」（画素を読む・自己テスト）が入っています。

**09・10・11・15 で目が疲れた・気分が悪くなったら、すぐに画面から目を離して休んでください。** 10 の回転は、明暗の切りかわりが 1 秒に 3 回までに制限してあります。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です（° は `deg`、✓ は `OK`）。英語の説明は長くなるので、操作の説明を 2〜3 行に分けています。09・10・11・15 には "Look away if you feel unwell" の注意を出します。
- **自己テストのしかた**：p5.js 版は描いた画面の画素を `loadPixels` で読みます。こちらは図を「形のリスト」（長方形・円・線分・多角形・画像。色は 0〜255 の整数）として作り、同じリストから画面の絵と、画素の真ん中の色を読む関数 `readPix` の両方を作ります。だから、テストが読む色と長さは、画面に描くものとまったく同じデータです。項目は p5.js 版と同じで、全部で 94 項目（06・09 は 5 項目、ほかは 6 項目）。結果は端末に出し、画面左下に `Self-test OK 6 / 6` のように出します。
- **05 影の中のチェッカー**：床の明るさは p5.js 版と同じ整数の式で計算しますが、4 × 4 px ごとに 1 回計算した 320 × 200 の画像を 4 倍にして表示します。そのためマスのふちと影のぼかしが少しカクカクします。A・B の値と、黒マスを 40・70・130・170 にしたときの確認は、作り直したその画像から読みます。
- **03 廊下の巨人**：人の胴は角の丸くない長方形です。遠近法の計算は Double で行います。
- **08 ヘルマン格子**：DoG フィルタの計算は p5.js 版と同じです（2 px を 1 画素、分離型ガウス、端は端の画素をくり返す）。一度に計算すると時間がかかるので、16 行ずつ数フレーム（約 0.3 秒）に分けて計算し、その間は前の画像と "computing" の表示を出します。
- **09 周辺視ドリフト**：絵はキーを押したときだけ作り直します。T のときは 0.5 秒ごとに画素を読んで比べます。
- **10 運動残像**：水玉の乱数は固定の種（48）から作りますが、p5.js の `randomSeed(48)` とは並びが違います。安全の上限（腕の数 × 速さ ≤ 3 回/秒）は、キーで変えるときと回転を計算するときの両方でかけます。
- **11 補色残像**：3 つの絵は 1/2.5 の解像度（318 × 198 画素）で作って拡大するので、ふちが少しカクカクします。自己テストはその全画素を調べます。
- **12・13**：点線は短い線分を並べて描きます。12 のネオンのモードでは、文字が読めるように説明の後ろに明るい帯を敷きます。13 の 3D は自分で回転・投影し、奥から順に塗ります。
- **14 シェパード音**：Web Audio の連続した音の代わりに、Art.Sound の `playTone` で短い音を鳴らします。1 段ごとに、1 オクターブずつ離れた倍音を同じガウスの重みの音量で同時に鳴らす和音にした「階段のシェパード音階」です（重み 0.01 未満の倍音は省き、同時に 6 音まで、1 音の長さは 1 段の 0.9 倍）。なめらかモード（2）では絵は毎フレーム動きますが、音は 0.25 秒ごとの和音で、高さは 1/24 オクターブ刻みです。ブラウザの圧縮器はありません。p5.js 版と同じく、最初のクリックかキーで鳴りはじめます。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。カメラがないとき・C を押したときは、p5.js 版と同じくテスト画像を使います。`S` の保存は PNG ではなく SVG です。
