# シリーズ67：情報幾何学 ─ Haskell コード集

確率分布を「点」と見て、分布の集まりを曲がった空間（多様体）として調べる ― **情報幾何学**を、見て・動かして・確かめるコード集です。確率の三角形と KL ダイバージェンス、フィッシャー情報とクラメール-ラオの限界、双曲平面になる正規分布の族から始めて、指数型分布族の 2 つの座標（θ と η）、e-測地線と m-測地線、ピタゴラスの定理と射影、ブレグマン・ダイバージェンス、自然勾配、EM 法、最大エントロピー、α-ダイバージェンス、相互情報量、球の上のフィッシャー-ラオ距離、そして音とカメラまで、どれも**ライブラリを使わずに本当に計算した**シミュレーションです。p5.js 版と同じ計算（0·log 0 = 0 の扱い、確率の三角形の重心座標と等高線、スコアの分散としてのフィッシャー情報、正規分布の測地線の閉じた式・数値積分・RK4、ψ・η = ∇ψ・ルジャンドル変換、ニュートン法による e-射影と最大エントロピー、周辺分布の積による m-射影、フィッシャー行列の連立方程式を解く自然勾配、EM 法と自由エネルギー、反復比例あてはめ、球への写像 p → 2√p）を Haskell（gloss）で書き直しています。種つきの乱数も p5.js 版と同じ列を同じ順に引くので、シミュレーションの結果や自己テストの数は p5.js 版と同じになります。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series67/

## 使い方

```
cabal run s67-00
```

番号を変えると別のスケッチが動きます（`s67-01`、`s67-15` など）。どのスケッチも一番下に「情報幾何の道具」（エントロピー・KL・フィッシャー-ラオ距離・α-ダイバージェンス、e と m の測地線、確率の三角形の座標と等高線、棒グラフ、正規分布の測地線、連立方程式、種つきの乱数、自己テストなど）が入っています。図の読み方：三角形の中の点 = 3 つの結果の確率分布（頂点 = 必ずその結果、まん中 = 3 つが同じ確率）。オレンジ = m（確率を混ぜる）側、紫 = e（対数で混ぜる）側、緑 = フィッシャー-ラオの測地線や「ぴったり 0」の確かめ。KL は「ナット」（自然対数）と「ビット」（log₂）の両方が出てきます。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます（C で切りかえ）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語やギリシャ文字・記号を出せないので、説明は短い英語で、記号は ASCII で書きます（θ η ψ φ μ σ α λ は `theta` `eta` `psi` `phi` `mu` `sigma` `alpha` `lambda`、D(p‖q) は `D(p||q)`、√ は `sqrt`、Σ は `sum`、∇ψ は `grad psi`、θ·η は `theta.eta`、½ は `1/2`、² は `^2`、eˣ は `e^x`、≈ は `~`、∝ は `~`、≤ ≠ は `<=` `!=`、⊕ は `xor`、∞ は `inf`、→ は `->`、⇔ は `<->` / `<=>`、π は `pi`）。名前も英語です（00 のグー・チョキ・パーは Rock / Scissors / Paper、01 の頂点は outcome 1〜3、05 は p1 p2 p3、06 は x = 0/1/2 と x0 y0 …、11 は #1 #2 #3、04 の族は Bernoulli / Poisson / 3 categories / Normal、14 のドレミは Do Re Mi … HiDo、15 の色は blk gray wht red yel grn blue pur、いま / 基準 は now / ref）。p5.js 版で 11〜13 px の小さな文字は 14 px にしたので、長い説明は短くしたり 2 行に分けたりして、いくつかの枠や文字の位置を少しずらしています。棒や枠の角は丸くありません。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 100 項目）。結果は起動時に端末に出し、画面右下にも `Self-test OK 6 / 6` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。項目名に入る数も p5.js 版と同じですが、06 の「最大誤差」だけは exp・log の最後の桁のちがいでわずかにちがうことがあります（例 5.3e-15 と 6.2e-15。判定は同じ）。`toExponential` の数は JavaScript と同じ書き方（`1.2e-15`、`0.00e+0`）で出します。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、1 本の乱数の列を同じ順に引きます。setup で種をつけ直さないスケッチ（00・01・05・06・13）は、p5.js 版と同じく自己テストのあとの列の続きを使うので、サンプル列や R の「でたらめ」も p5.js 版と同じになります。
- **等高線の地図**：p5.js 版の createGraphics の代わりに、ピクセル画像を一度だけ作って World にしまい、入力（分布や画面の大きさ）が変わったときだけ作り直します。三角形の外は透明ではなく背景の色で、線の半透明も背景の色と混ぜた色にしています。
- **01 KL ダイバージェンス**：右の 2 つの等高線は、p5.js 版と同じく p（小数 3 桁）か画面の幅が変わったときだけ作り直します。
- **02 フィッシャー情報**：1 フレーム 300 回の実験は、同じ乱数の順のまま速いループで計算します。
- **03 正規分布の族**：A からの距離の等高線は A か画面の大きさが変わったとき、測地線（半楕円 400 点、RK4 400 歩）と長さの数値積分（4000 点）は A・B が変わったときだけ計算し直します。RK4 の点線は短い線分を並べて描きます。
- **07 ブレグマン・ダイバージェンス**：Backspace は gloss の Backspace と Mac の delete キーの両方で効きます。
- **08 自然勾配**：(μ, log σ) の道の点線は短い線分を並べて描きます。
- **09 EM 法**：log L の等高線は、各列の w1 N(x; μ1) と各行の w2 N(x; μ2) を先に表にしてから作ります（同じ絵。描く範囲では和が 1e-300 より小さくならないので max(1e-300, …) は省きました）。データか画面の大きさが変わったときだけ作り直します。
- **11 α-ダイバージェンス**：α は 0.1 きざみの 21 通りなので、正規分布での近似（格子 → パターン探索、計算は p5.js 版と同じ）は起動時に全部計算しておきます。
- **12 相互情報量**：3 変数の反復比例あてはめ（IPF）は、毎フレームではなく表が変わったときだけ計算します（答えは同じ）。
- **13 球に乗せた分布**：WEBGL と orbitControl の代わりに、`V3` の回転と透視投影（p5.js の既定のカメラと同じ距離）、奥から順に描く（`depthSort`）自前のカメラで描きます。ドラッグの回転も自前です（1 ピクセル = 0.01 ラジアン）。球の面は頂点の色をなめらかに混ぜず、三角形ごとに 1 色（3 頂点の平均）です。格子と曲線は面より少し手前として重ねるので、横から見ると裏側の線が少し透けることがあります。p と q の点は小さな球ではなく円です。
- **14 分布を聞く**：Web Audio の代わりに Art.Sound の `playTone` を使います（三角波 0.35 秒、音量 0.35 × `master` 0.12）。拍は `audioCtx.currentTime` ではなく経過時間 `envTime` で計り、音を先に予約できないので、0.1 秒先までの拍をその場で鳴らします。p5.js 版と同じく、クリックかキーで音が ON になります。
- **15 カメラ映像の色の分布**：カメラは Art.Device（ffmpeg 経由、64 × 48、左右反転）で読みます。カメラがないときや C で切ったときは、p5.js 版と同じテスト画像を使います。画素とヒストグラムは unboxed ベクトルで持ちます。`S` の保存は PNG ではなく SVG です。
