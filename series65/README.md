# シリーズ65：マルコフ連鎖 ─ Haskell コード集

**「次にどうなるかは、今の状態だけで決まる」** 確率の動き ― マルコフ連鎖のコード集です。天気の連鎖と遷移行列から始めて、n ステップ後の分布、定常分布、状態の分類、ギャンブラーの破産、すごろくの平均手数（基本行列）、グラフ上のランダムウォーク、トランプを何回切ればよいか、文字の n-gram による文章生成、隠れマルコフモデル、連続時間マルコフ連鎖、メトロポリス-ヘイスティングス法とギブスサンプリング、エーレンフェストの壺、そして自分の演奏やカメラ映像から学ぶ連鎖まで、どれも**行列の計算とシミュレーションをゼロから実装して、答えが一致することを確かめる**スケッチです。p5.js 版と同じ計算（部分ピボットのガウスの消去法による定常分布と基本行列、べき乗法、タージャンの強連結成分と周期、上昇列による全変動距離、前向き・後ろ向きアルゴリズム、一様化、メトロポリス法とギブスサンプリング、k 平均法）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。種つきの乱数も p5.js 版と同じ列を同じ順に引くので、シミュレーションの結果は p5.js 版と同じ値になります。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series65/

## 使い方

```
cabal run s65-00
```

番号を変えると別のスケッチが動きます（`s65-01`、`s65-15` など）。どのスケッチも一番下に「マルコフ連鎖の道具」（行列の計算、定常分布、状態の分類、遷移図やグラフを描く道具、種つきの乱数、自己テストなど）が入っています。長いシミュレーションは 1 フレームに少しずつ進めるので、画面は止まりません。記号：遷移行列 P（`transP !! i !! j` = i の次に j へ行く確率、各行の合計 = 1）、分布 μ（横ベクトル、画面では `mu`）、定常分布 π（π P = π、画面では `pi`）、基本行列 N = (I − Q)⁻¹、生成行列 Q（連続時間、各行の合計 = 0）。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や記号を出せないので、説明は短い英語で、記号は ASCII で書きます（π は `pi`、μ は `mu`、σ は `sigma`、ρ は `rho`、≈ は `~`、⇔ は `<->`、² は `^2`、log₁₀ は `log10`、①②③ は `(1)(2)(3)`、∞ は `inf`）。状態の名前も英語です（00 の晴れ・くもり・雨は Sunny / Cloudy / Rain、01 の家・学校・公園・店は Home / School / Park / Shop、10 の稼働・点検・故障・修理は Run / Check / Fail / Fix、14 のドレミは Do Re Mi …）。文字は 14 px より小さくしないので、長い説明は短くしたり 2 行に分けたりしています。パネルやマスの角は丸くありません。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 126 項目）。結果は端末に出し、画面右下にも `Self-test OK 7 / 7` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。00 の 4 番目の項目名は、p5.js 版では「(21, 24, 17) / 62」と書かれていますが、実際に確かめている値（24, 22, 15）/ 61 に直しました。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、乱数の列を 1 本だけ持って引く順番もそろえた（乱数を順に引く小さなモナド `R`）ので、シミュレーションの結果は p5.js 版と同じです。
- **行列**：行列は行のリストで持ちます。連立方程式は p5.js 版と同じ部分ピボットのガウスの消去法で、逆行列は全部の列をいっしょに消去します（列ごとに解くのと同じ計算なので、答えも同じです）。
- **時間で区切るシミュレーション**：p5.js 版が「1 フレームに 6 ミリ秒ぶん」のように時間で区切っている所は、1 フレームに決まった量だけ進めます（04 は 30000 歩ぶんのゲーム、05 はふつう 3000 歩・F で 12000 歩ぶんのゲーム、11 の「全力」は 2000 歩、12 の「全力」は 3000 回（例 1）または 20 スイープ（例 2）、13 の「全力」は 3000 回）。乱数を引く順は同じです。
- **点線**：02・13 などの点線は、短い線分を並べて描きます。04 のゲームの道のり（40 本）は細い線で描きます。
- **02 定常分布**：シミュレーションの誤差のグラフの点が 2000 個をこえたら、1 つおきに間引きます（いちばん古い点は残します）。
- **08 文字の n-gram**：gloss のフォントは日本語を書けないので、はじめは英語の文章で始めます（T で日本語）。日本語のときは、生成した文と遷移表の文字を 16 進 4 けたの文字コード（`306e` = の など）で表示し、文章の枠には最初の約 140 文字だけを出します。学習・生成・エントロピー率・コピーの割合の計算は p5.js 版と同じです（文字列は `String` で、1 文字 = 1 つの文字コードは `Array.from` と同じ。文脈と次の文字は JavaScript の Map と同じく初めて出た順に持ち、確率の大きい順に安定に並べかえます）。英語の文は 1 文字ずつ等間隔に並べます。英語から始めるので、画面に出る文章は p5.js 版（日本語から始める）とはちがう乱数で作られます。
- **10 連続時間マルコフ連鎖**：自己テストの行列の指数関数で、2 で割る回数 s を log₂ の切り上げではなく 2 のべきとくらべて正確に決めます（答えは同じ）。
- **11 メトロポリス-ヘイスティングス**：目標の色と等高線の背景は 1/3 の大きさで作って 3 倍にのばすので、等高線は少し太く角ばっています。ヒストグラムはその背景に自分で色を混ぜて描きます（p5.js 版と同じく 10 フレームごとに更新）。
- **12 ギブスサンプリング**：例 1 の点（消えないキャンバス）は、1/3 の大きさの「濃さ」の配列（unboxed）にためて、3 倍にのばして描きます。
- **13 エーレンフェストの壺**：2 項分布 C(N, k)/2^N は、p5.js 版の対数の計算ではなく、Haskell の `Integer` で分数としてぴったり求めてから小数にします（1/π_N = 2^N がちょうどになります）。2^N の表示も `Integer` で計算します。n 回後の分布は 3 重対角の行列だけを掛ける速い版で計算します（足し算の順は同じで、値も同じです）。
- **14 その場で学ぶマルコフ音楽**：Web Audio の代わりに Art.Sound の `playTone` を使います（三角波 0.4 秒、音量 0.6 × `master` = 0.072）。即興のタイミングは `millis()` ではなく経過時間 `envTime` で計ります。お手本のフレーズは p5.js 版と同じ日本語の文字列から読みます。
- **15 カメラ**：カメラは Art.Device（ffmpeg 経由、64 × 48、左右反転）で読みます。カメラがないときや C で切ったときは、p5.js 版と同じテスト画像（空・太陽・山・しまの畑）を使います。画素とラベルは unboxed ベクトルで持ちます。`S` の保存は PNG ではなく SVG です。
