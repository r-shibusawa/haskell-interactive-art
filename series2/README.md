# シリーズ2：フラクタル ─ Haskell コード集

「同じ形がどこまでも続く」フラクタルを、再帰・自己相似・複素数の順にたどりながら、自分の手で動かして遊ぶ 16 本を、Haskell（gloss）に移植したコード集です。円の中の円から始めて、フラクタルツリー、L-システム、シダ、シェルピンスキー、コッホ雪片、カオスゲーム、マンデルブロ集合とジュリア集合へ進み、声や音と組み合わせた作品で終わります。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series2/

## 使い方

```sh
cabal run s2-00
```

番号を変えると別のスケッチが動きます（`s2-07`、`s2-15` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 🎤 マイクは `ffmpeg` で読みます。使えないときはデモの信号で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。
- **保存**：S キーの保存は PNG ではなく SVG です。
- **クリック**：左ボタンだけに反応します。マウスを動かす前のマウス位置は、画面の左上ではなく中央です。
- **描く図形の数の上限**：毎フレーム描きなおすので、多すぎる図形は省きます。
  - 01 は枝を 1 本ずつではなく世代ごとに増やし、7400 本で止めます。入りきらない世代は間引きます（3 本枝で縮む割合が大きいときなど）。
  - 02 は茂りすぎた木（図形 7400 個超）が出たら、次の種の木に替えます。
  - 03 は画面の外の線を省き、それでも 7400 本を超える世代（草の世代 5 以上など）は、枝分かれの深い細かい枝を省きます。画面にそのことが表示されます。草の世代 7 では、世代を変えた瞬間に一瞬止まります。
  - 05 の深さの上限は三角形 8、カーペット 5 です（p5.js 版では右端のちょうど 1 点だけ 9、6 になります）。カーペットは 8 個の四角を塗る代わりに、全体を塗ってから穴を背景色で描きます。
  - 12 は森全体の図形が 7400 個を超えると、古い木から消えます。
  - 13 も全体を塗ってから穴を描きます。3 ドットより小さい穴は描きません。文字の後ろに暗い帯を足しました。
- **点を描きためるしくみ**：04・07 は点をピクセル画像にためます。画面より粗く（1 ピクセルが約 2.3 ドット）、点 1 つの濃さも変えています。範囲は 04 がシダのまわり、07 が頂点の入る範囲です。
- **マンデルブロ（08）**：画像は 356 × 222 で、画面いっぱいに拡大します（p5.js 版は画面のピクセルごとに計算）。画面が止まらないよう、ズームのあとは数フレームかけて上から順に描きかえます。配色の変更はすぐに反映されます。
- **木の形（12）**：枝のゆらぎを植えたときに決めるので、育つ途中で形が変わりません（p5.js 版は段が増えるたびに少し変わります）。
- **音（11・12）**：Web Audio の代わりに、波形のファイルを再生コマンドで鳴らします。発音まで少し遅れ、同時に 8 音までです。11 は先の時刻に予約せず、その時刻が来たときに鳴らします。
- **マイク（10・15）**：マイクが使えないときは止まらずにデモの信号で動きます。
