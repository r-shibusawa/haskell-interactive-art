# シリーズ26：オリガミクス ─ Haskell コード集

1 枚の紙を「折る」ことを数学として動かすスケッチ 16 本を、Haskell（gloss）に移植したコード集です。折り紙の公理、定規とコンパスではできない作図（角の三等分・∛2）、芳賀の定理、平らにたたむ条件（前川・川崎の定理）、ミウラ折りや吉村パターンの工学、ドラゴン曲線までを体験します。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series26/

## 使い方

```sh
cabal run s26-00
```

番号を変えると別のスケッチが動きます（`s26-07`、`s26-14` など）。

- 🔊 音を使うスケッチ（13・14）は `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 📷 カメラ（15）は `ffmpeg` で読みます。使えないときは模様の紙になります。

## p5.js 版との違い

- 画面の文字は英語で短くしました（gloss の文字は ASCII のみ）。∛2 は cbrt(2)、θ は theta や th と書きます。11 の「億 km」は x10^8 km です。
- 紙の上の白い文字は読めないので、01 の P1・P2 は濃い色にしました。
- 計算の精度：02・03・08・11 は p5.js と同じ Double で、そのほかは Float です。01 の直線の平行判定と 00・15 の多角形の切り分けは、Float に合わせて許容誤差を 1e-3 程度に広げました。
- 00：面が 512 枚をこえる折りはしません。15：面が 64 枚をこえる折りはしません。
- 03：∛2 の立方体は枠からはみ出さない位置に動かし、描く大きさだけ制限しています（体積の数字はそのままです）。
- 08・09・10（3D）：WebGL の代わりに、自前の透視投影と画家のアルゴリズムで描きます。面の明るさは面の向きから計算し、視点はドラッグ（回転）とホイール（距離）だけです（右ドラッグの平行移動はありません）。重なった面の前後は完全には判定できないので、平らにたたむ直前は面が入れかわって見えることがあります。08 の板は細かいマスに分けて描きます。
- 08・09：自動運転の折り返しを少し直しました（08 は折り目を開ききったところで止まらず折り返します。09 は端で向きが毎フレーム変わらないようにしました）。
- 11：スライダーの文字はスライダーの上に、目盛りの文字は重ならないよう 2 列に置きました。
- 12：線分が 6,000 本（4 匹のときは合計）をこえるときや、太さが 1.5 px 未満のときは細い線で描きます。
- 13：音は Art.Sound で鳴らします。発音まで少し遅れ、同時に鳴るのは 8 音までです。太鼓は音の高さが下がらない低いサイン波（70 Hz）、シャカはノイズではなく短い高音の矩形波です。テンポを上げすぎると音が間引かれます。
- 14：S の保存は PNG ではなく SVG です。線分は 400 本まで、Z で戻れるのは 100 回までです。線が多いときは描く要素を減らすために、右のタイル 1 枚を大きくします。
- 15：カメラは ffmpeg で読みます（320×240）。紙は 1 画素ずつ計算し、2.5 倍に拡大して表示するので、p5.js 版より粗く見えます。折った面の影はありません。PAPER の文字は 5×7 の点の文字です。S の保存は SVG です。
