# シリーズ18：NP完全性と近似アルゴリズム ─ Haskell コード集

答えを確かめるのはかんたん、見つけるのは難しい。P と NP、還元による NP 完全性の証明、そして「最適でなくても保証つき」の近似アルゴリズムを体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

参考：Cormen ほか『Introduction to Algorithms』

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series18/

## 使い方

```sh
cabal run s18-00
```

番号を変えると別のスケッチが動きます（`s18-07`、`s18-13` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 画面の文字は英語です。Space はスペース、Left / Right / Up / Down は矢印キーのことです。
- 総当たりのスケッチは、画面が固まらないよう探索を少しずつ（フレームごとに）進めます。

## p5.js 版との違い

- **1 手ずつ止まるしくみ**（03・05・13・14）：JavaScript のジェネレーター（`function*` と `yield`）の代わりに、各スケッチの下にある小さな `Gen` を使います。アルゴリズムの書き方は同じで、結果は「状態の遅延リスト」になります。
- **画面の文字**：gloss のフォントは日本語や記号を表示できないので、画面の文字は英語です。論理記号は `~`（否定）、`&`（かつ）、`|`（または）、`->`（ならば）、`<->`（同値）、○× は `O` `x`、✓✗ は `OK` `X`、½ は `1/2` と書きます。15 の ε と δ は `e` と `d` です。読みやすさのために文字は 14 以上にしたので、説明を短くした所や 2 行に分けた所があります。
- **角と破線**：四角の角は丸くなりません。破線は短い線を並べて描きます。14 の紫の点線の輪も短い線の並びです。
- **05**：節のラベルが点に重ならないよう、横の節のラベルを少し外に、下の説明文を少し下に置きました。
- **08**：表の左の見出しは `none`、`up to 34` のように書きます。
- **10**：2-opt の改善は最大 1000 周で打ち切ります。ふつうはその前に止まります。最適解は 4 の段階を初めて見るときに計算します。同じ長さの巡回路が複数あるときは、p5.js 版と違う巡回路を描くことがあります。
- **12**：音は波形のファイルを再生コマンドで鳴らすので、発音まで少し遅れ、同時に 8 音までです。速さを上げると鳴らない音が出ます。音を出すための最初のクリックは不要です。節のマスは文字が読めるよう 5 列 8 行にしました（p5.js 版は 10 列 4 行）。
- **13**：音の遅れと同時発音数は 12 と同じです。答えの音は、全部を同時に予約する代わりに、0.16 秒おきに順に鳴らします。
- **15**：リストの棒は 1 本ずつではなく、全体を 1000 に分けた幅で近い値をまとめて、つながった帯として描きます。リストの個数と答えの計算は間引かずに行います。
