# シリーズ33：貴金属比 ─ Haskell コード集

黄金比 φ、白銀比 1+√2、青銅比 …… 長方形から正方形を n 枚取ると同じ形が残る「貴金属比」φn = (n + √(n²+4)) / 2 の仲間たちを、連分数・数列・螺旋・紙・植物・準結晶・音・カメラで体験する 16 本を、Haskell（gloss）に移植したコード集です。「白銀比」は日本で昔から使う √2 ≈ 1.414（A 判の紙）と、貴金属比の 1+√2 ≈ 2.414 の 2 種類があるので、文脈で区別しましょう（スケッチ 00）。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series33/

## 使い方

```sh
cabal run s33-00
```

番号を変えると別のスケッチが動きます（`s33-07`、`s33-14` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 📷 カメラは `ffmpeg` で読みます。使えないときは作った風景（夕日と山）で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は短い英語です。√ や φ も `sqrt`、`phi` と書きます。14 より小さい文字は 14 にそろえたので、表の列の位置や 00・03・05・06・07・08・10・13 の配置を少し変えています。
- **保存**：14 の S と 15 のスペースの保存は PNG ではなく SVG です。
- **数の計算**：03 の数列は `Integer` で計算するので、大きな項も桁落ちせず全桁を表示します。
- **01**：自由な比のモードで 1 段に 200 枚を超える正方形は、200 枚までしか描きません（細すぎて見えない場合だけです）。
- **05**：小さすぎる紙（短い辺が 18 ピクセル未満）には名前を書きません。
- **09**：マスの下の位の値は、マスに入るように短く書きます（`.618`、`199`、`8e6` の形）。
- **12**：絵 3 の文字 φ はフォントで描けないので、楕円と縦棒で描いています。
- **13**：Web Audio の代わりに波形のファイルを再生コマンドで鳴らすので、発音まで少し遅れ、同時に 8 音までです。「ドン」は音程の下がらない短い低音です。リズムは先読みせず、時刻が来たら鳴らします。最初にクリックしなくても音が出ます。
- **14**：描きためる層の代わりにスタンプを覚えておき、図形が約 6800 個を超えると古いものから消えます。線の太さ 2 の螺旋と星は、細い線を 2 本ずらして重ねています。音は 🔊 13 と同じしくみです。
- **15**：カメラは 320 × 240 に縮小して読み、拡大して表示します。カメラの向きは `startCamera` で左右反転しています。
