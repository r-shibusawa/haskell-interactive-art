# シリーズ42：マトロイド理論 ─ Haskell コード集

「独立」を抽象化する。ベクトルの線形独立とグラフの「閉路なし」は同じ構造 ─ それがマトロイド。独立集合・基・サーキット・階数・閉包の公理から、貪欲法が必ず最適になる理由（マトロイド = 貪欲法がいつも正しい構造）、双対・マイナー・表現可能性・マトロイド交差までを、小さな台集合（8〜12 要素）を自分の手で動かして体験するコード集です。p5.js 版と同じ計算を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series42/

## 使い方

```
cabal run s42-00
```

番号を変えると別のスケッチが動きます（`s42-01`、`s42-15` など）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や記号を出せないので、説明は短い英語です。✓ ✗ は `[ok]` `[x]`、∅ は `{}`、∪ ∩ は `u` `n`、≤ は `<=`、∖ は `\`、F_7^- は `F7-` と書きます。文字が広いので、右のパネルは p5.js 版より少し幅が広く、行も折り返しています。パネルの角は丸くありません。
- **小さな文字**：p5.js 版で 11〜13 の文字は、読みやすいよう 14 にしています。
- **00 ベクトル**：パネルと重ならないよう、原点を少し左（幅の 0.33 倍）に置いています。
- **05 階数と閉包**：パネルの幅のぶん、格子の列が 1 本少なくなっています。最初から同じ直線に乗せる 3 点は、格子からはみ出さないよう左へずらします。
- **08 定理**：ヒストグラムの数字は、重ならないよう 1 本おきに高さを変えています。
- **12 マトロイド交差**：p5.js 版の増加路探索は「辺番号 0」を未到達と見誤るため、まれに同じ道を戻り続けるおそれがあります。こちらは到達済みかどうかを正しく調べます。
- **13 貪欲法を聴く**：音は OS の再生コマンドで鳴らすので、最初のクリックは不要です。発音までに少し遅れがあります。音量の立ち上がりと減衰は `playTone` のものです。
- **14 全域木ブラシ**：`S` の保存は PNG ではなく SVG です。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。ffmpeg やカメラが無いときは、180 フレーム待ってから p5.js 版と同じノイズ点群になります。映像は半透明にする代わりに、暗い膜を重ねています。
