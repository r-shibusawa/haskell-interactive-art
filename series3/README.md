# シリーズ3：人工生命（ALife）─ Haskell コード集

「生きているとはどういうことか」を、単純なルールのくり返しから生まれる動きで考えるコード集です。セル・オートマトン、群れ、生態系、進化を、Haskell（gloss）で書いたスケッチを動かして観察します。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series3/

## 使い方

```
cabal run s3-00
```

番号を変えると別のスケッチが動きます（例：`cabal run s3-13`）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。
- **保存**：S キーの保存（00・13）は PNG ではなく SVG です。
- **画面の大きさ**：マス目の数は 1280 × 800 のウィンドウに合わせた固定の値です。起動時の画面の大きさでは決まりません。
- **描いたものを残すしくみ**：gloss は毎フレーム描きなおします。
  - 00 は足あとを 6000 本まで線で覚えていて、超えると古いものを 356 × 222 のピクセル画像に焼きつけます。古い足あとは少し粗くなります。
  - 05・11・13 の残像は、数フレーム前の位置を薄く重ねて再現しています。
- **同時に更新**：05・11 の鳥と 06 のアリは、前のフレームの状態を見て全員が同時に動きます（p5.js 版は 1 匹ずつ順に書きかえるので、あとの鳥は先に動いた鳥を見ます）。06 のにおいは、そのフレームの移動の前にまとめて落とします。
- **08 のエサ**：増えすぎて重くならないよう、2000 個までにしました。超えると古いエサから消えます。
- **15 の画面**：計算は p5.js 版と同じ 426 × 266 のマスで行いますが、表示する画像は少し粗い 355 × 222 です。
- **角丸**：10・12 のセルの角は丸めず、斜めに落としています。
- **音（10・12）**：Web Audio の代わりに、波形のファイルを再生コマンドで鳴らします。発音まで少し遅れ、同時に 8 音までです。
- **マイク（11）**：マイクが使えないときは、止まらずにデモの信号で動きます（画面にそう表示します）。
