# シリーズ53：天体（地球と宇宙） ─ Haskell コード集

足元の地球から宇宙の果てまで、**計算で確かめる天文学**。昼と夜・季節、月の満ち欠けと日食・月食、潮汐、星空の回転から、軌道要素とケプラー方程式で計算する惑星の位置と逆行、ホーマン軌道とスイングバイ、黒体放射と星の色、HR 図、距離のはしご、系外惑星、銀河の回転曲線と宇宙の膨張まで、実際の式と実際のデータ（おおよその値）で計算し、数字はすべて画面に出します。p5.js 版と同じ計算（ユリウス日、ケプラー方程式のニュートン法、RK4、プランクの式の数値積分、最小二乗法、同じ種の乱数）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series53/

## 使い方

```
cabal run s53-00
```

番号を変えると別のスケッチが動きます（`s53-01`、`s53-15` など）。どのスケッチも一番下に「天文の道具」（ユリウス日、軌道要素とケプラー方程式、グラフ、自己テストなど）が入っています。画面の左下（07 は右下）の `Self-test OK n / n` は、起動時に計算を手で確かめられる値と照合した結果です（端末にも出ます）。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です（δ は `delta`、β は `beta`、° は省略、² は `2` や `^2`）。長い説明は 2 行に分け、表や説明文の位置を少し変えています。星・惑星・衛星の名前、01 の食の種類（`solar` / `lunar`）と月の形の名前、06 の結果のメッセージも英語です。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差で照合します（全部で 112 項目）。結果は端末に出し、画面の隅にも `Self-test OK 8 / 8` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけ）。
- **いまの時刻**（01・03・04・05 の起動時と R キー）：`Date.now()` の代わりに C の `time()` で読むので、秒の単位までです。
- **時間の進み方**：p5.js 版と同じく 1 フレームごと（1/60 秒ぶん）に進めます。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、引く順番もそろえたので、種を決めた計算（10 の遠くの星、11 の観測データ、12 の星と観測点、13 のぶどうパンの格子、15 のテスト画像、自己テスト）は p5.js 版と同じ数になります。`Date.now()` や `Math.random()` で決める種・位置（06 の最初の位置、10 の測定誤差、11・13 の新しいサンプル）は `randomRIO` で決めます。
- **点線と切り抜き**：`setLineDash` と `clip` が無いので、点線は短い線分を並べて、枠の外を消す所は線分を枠で切って描きます（06・07・09）。
- **02 潮汐**：観測地点の潮位のグラフは、止めている間は同じ点を足しません（p5.js 版は毎フレーム同じ点を足し続ける）。点が多いときは 600 点ほどに間引いて描きます（形は同じ）。
- **03 星空の回転**：gloss は前の画面を残せないので、軌跡は全天を 274 × 274 のます目（1 ます約 2.4 ピクセル）にためた画像で描きます。p5.js 版より少し粗く、星座の格子線は軌跡の上に描かれます。
- **04 惑星の位置**：「円の間隔」の文字は自己テストの表示と重ならないよう、軌道の図の右下に置いています。
- **07 スイングバイ**：下の数字の行は右のグラフと重ならないよう 6 行に分けています。GM は `1.267e+8` の形で表示します。
- **08 黒体放射**：見える光の帯は 400 × 1 画素のピクセル画像を引き伸ばして描きます。
- **09 HR 図**：寿命は「億年・百万年」の代わりに Gyr（10 億年）・Myr（100 万年）で表示します。
- **11 系外惑星**：B の周期の自動探索（1102 回の折りたたみ）は p5.js 版と同じくその場で計算するので、そのフレームだけ約 40 ms かかります。
- **14 惑星の音楽**：Web Audio の代わりに Art.Sound の `playTone` で鳴らします（通過音は三角波、F の和音は正弦波を 0.25 秒ずつ `envTime` で予約）。全体の音量 `master` = 0.15 は同じです。最初のクリックは要りません。音は再生コマンドの起動ぶん少し遅れます。
- **15 カメラで星の軌跡**：軌跡の画像は 8 万画素以下にするため 320 × 200（p5.js 版は 400 × 250）です。カメラは ffmpeg 経由で 160 × 120 で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像になります。`S` の保存は PNG ではなく SVG です。
