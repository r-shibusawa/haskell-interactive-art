# シリーズ5：信号処理 ─ Haskell コード集

「波」を見て、聞いて、分解する。正弦波と波の足し算から始めて、サンプリング、量子化、フーリエ変換、フィルタを、音と画像で体験する 16 本を Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series5/

## 使い方

```sh
cabal run s5-00
```

番号を変えると別のスケッチが動きます（`s5-07`、`s5-13` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 🎤 マイク・📷 カメラは `ffmpeg` で読みます。使えないときはデモの信号や映像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は英語です。長い説明は 2 行に分けています。08・13 は波が文字にかからないよう、文字の後ろに帯を敷いています。
- **音**：Web Audio の代わりに、波形のファイルを再生コマンドで鳴らします。発音まで少し遅れ、同時に 8 音までです。連続音は短い音のくり返しになり、1 音ごとに音量が減衰します。使える波形は正弦波・三角波・矩形波・のこぎり波だけなので、次のスケッチは近似です。
  - 01：波が 4 個までは正弦波を 1 つずつ鳴らします。5 個以上は 30 個の正弦波の代わりに、完成した波形（矩形波など）の音で代用します。
  - 04：量子化した波形をそのまま再生できないので、波形をフーリエ係数に分解して大きい成分を 4 つまで鳴らします（1 ビットは矩形波）。細かい量子化ノイズは聞こえません。
  - 10：本物のフィルタは通していません。倍音ごとに応答の式をかけて計算し、大きい成分を 4 つまで鳴らします。水色のスペクトルも実際の音の分析ではなく、同じ計算の結果を棒で描いたものです。
  - 12：描いた波形のスペクトルから大きい倍音を 4 つまで選んで鳴らします。波形そのものの再生ではありません。
  - 15：うなりが聞こえるように 1 秒の音をくり返します。マウスで変えた周波数は次の音から反映されます。差が 1 Hz より小さいと、ゆれの全体は 1 音の中に収まりません。
- **マイク**：マイクが使えないときは止まらずにデモの信号で動きます。サンプリング周波数は 22050 Hz で、1 bin は約 43 Hz（p5.js 版は約 86 Hz）です。
  - 07：縦軸の範囲（11 kHz・5.5 kHz）を保つため、1・2 キーは 256・128 bin を表示します。地図は 427 × 185 マスのピクセル画像に描きためます。
  - 11：波形は最新の 512 点（約 23 ミリ秒、p5.js 版は 2048 点で約 46 ミリ秒）で、自己相関の計算は p5.js 版と同じです。窓が短く周期の倍数を選びやすいので、最大値に近い山のうち最初のものを選び、サンプリング周波数が半分なぶんは放物線で頂点を細かく求める処理を足しています。
- **06 エピサイクル**：1 回に描ける点は 3000 点までです。
- **09 画像フィルタ**：カメラが使えないときはデモ映像で動きます。
