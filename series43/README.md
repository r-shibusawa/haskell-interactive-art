# シリーズ43：双対性 ─ Haskell コード集

数学のあちこちに現れる「裏返しても同じ」構造 ─ 双対性。点と直線、多面体の頂点と面、ボロノイとドロネー、線形計画の主問題と双対問題、凸関数とルジャンドル変換、AND と OR、流れとカット、時間と周波数。見た目はちがっても同じ骨組みを持つ対を、2D/3D のインタラクティブなスケッチで体験するコード集です。p5.js 版と同じ計算を Haskell（gloss）で書き直しています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series43/

## 使い方

```
cabal run s43-00
```

番号を変えると別のスケッチが動きます（`s43-01`、`s43-15` など）。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。文字は 14 より小さくしません。記号は ASCII で書きます（K° は `K^o`、θ は `t`、∧ ∨ ¬ は `& | ~`、✓ は `OK`、内積の点は `c.x`）。
- **01・07・08 の塗り**：頂点を内側へドラッグすると多角形が凹みます。gloss の `Polygon` は凸の形しか塗れないので、凹んだ形は `fillPoly` で横に細く切って塗ります。
- **05 相補性**：制約のラベルは、最適解の説明と重ならないよう線の中央ではなく 30% の位置に書きます。
- **06・07**：接線や極線、K° の輪郭は枠の中で切ります（p5.js 版は枠の外まで描きます）。
- **10 最大流**：カットの赤い印は数字の札に隠れないよう少し長くしました。
- **12 双対多面体**：WEBGL は使わず、面・辺・頂点を奥から順に描きます（画家のアルゴリズム）。明るさは面の向きから計算し、頂点の球は円で描きます。
- **13 音**：ブラウザの AnalyserNode の代わりに、鳴らした音と同じ信号をプログラムの中で作り、Blackman 窓・DFT・なめらかさ 0.5・−100〜−30 dB の同じ手順で解析します。標本は 22050 Hz × 1024 個（窓の長さは p5.js 版とほぼ同じ約 46 ms）です。音の包絡は Art.Sound のもの（立ち上がり 8 ms のあと減衰）で、長さは 10 ms 刻みに丸めます（最短 5 ms）。Art.Sound にノイズがないので、「ノイズ」はばらばらの高さののこぎり波 8 音を重ねた音で、本物のホワイトノイズより凸凹のあるスペクトルになります。発音までに少し遅れがあり、同時に鳴るのは 8 音までです。
- **14 双対ブラシ**：紙に焼きつけるのではなく、線をパネルごとに新しい順に 3500 本まで覚えて毎フレーム描き直します。超えると古いものから消えます（`maxInk`）。`S` の保存は PNG ではなく SVG です。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。ffmpeg やカメラが無いときは、p5.js 版と同じく動く点を母点にします。映像の薄い表示は、背景の色と混ぜた画像で代わりにしています。
