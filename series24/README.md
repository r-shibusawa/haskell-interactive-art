# シリーズ24：力学 ─ Haskell コード集

F = ma から始めて、運動量・エネルギー・角運動量の保存則、振動と波、惑星の運動、剛体の回転、最小作用の原理まで。古典力学の「法則」を、自分で動かせるシミュレーションで確かめるコード集を、Haskell（gloss）で書きました。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series24/

## 使い方

```
cabal run s24-00
```

番号を変えると別のスケッチ（`s24-01`、`s24-15` など）が動きます。

## p5.js 版との違い

- 画面は 1280×800 の固定で、ウィンドウの大きさには合わせません。画面の文字は英語です（gloss の文字は ASCII のみ）。角の丸い四角は普通の四角になります。
- 音を出す前のクリックは要りません。音は OS の再生コマンドで鳴らすので、少し遅れます（13・14）。
- 13：p5.js 版は全モードを足した波形を 1 つ作りますが、こちらは聞こえるモードのうち大きいものから 8 つを、別々のサイン波として同時に鳴らします。
- 14：残像（T）は半透明の塗り重ねではなく、過去 24 フレームまでの線を薄く重ねて描きます。ばねが多いときは重ねるフレーム数が減ります。S で保存するのは PNG ではなく SVG です。
- 11・12：WEBGL の代わりに、面を奥から順に塗る方法（画家のアルゴリズム）で描きます。陰影は簡単な計算で、面の重なりがまれにずれることがあります。12 の床はいつもコマの後ろに描くので、下から見上げてもコマは隠れません。
- 07：基準モードのパネルは、文字が入るように少し縦に長くしました。
- 08：太陽にぶつかった瞬間に計算を止めます。扇形は間引いた点で描きますが、面積はすべての点で計算します。
- 15：dS/dε と d²S/dε² は小さな差を調べるので、作用の計算だけ倍精度（Double）を使います。
- 時間グラフは 1 つおきの点で線を描きます。
