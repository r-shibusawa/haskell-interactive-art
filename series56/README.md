# シリーズ56：束論 ─ Haskell コード集

「順序」から生まれる代数 ― 半順序・上限と下限・束を、**本当に計算した有限の構造**で確かめるコード集です。矢印からハッセ図を作り、約数の束と部分集合の束で上限 = 最小公倍数・和集合を確かめ、分配束とモジュラー束（N5 と M3）、補元とブール代数、論理式の簡単化（クワイン-マクラスキー法）、ガロア接続と閉包、形式概念分析、束の不動点定理とプログラム解析、鎖と反鎖・ディルワースの定理・メビウス関数まで進みます。p5.js 版と同じ計算（ワーシャル法の推移的閉包、被覆とランク、上界の中の最小元としての上限・下限、全部の 3 つ組で調べる分配律・モジュラー律、導出作用素による概念束、クリーネの反復、増加道による二部グラフの最大マッチング、区間ごとの再帰のメビウス関数）を Haskell（gloss）で書き直しました。順序は n × n の表 `UArray (Int, Int) Bool`（`True` = 「i ≤ j」）で持っています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series56/

## 使い方

```
cabal run s56-00
```

番号を変えると別のスケッチが動きます（`s56-01`、`s56-15` など）。どのスケッチも一番下に「束論の道具」（順序の表・閉包・被覆・上限と下限・ハッセ図・種つき乱数・自己テストなど）が入っています。ハッセ図の辺 = 被覆（間にはさまる元がない組）、高さ = ランク（下からの最長の鎖の長さ）です。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です（07 の性質・08 の動物と特徴の名前も英語）。記号は ASCII で書きます（≤ ⊆ は `<=`、∨ ∧ は `v` `^`、∪ ∩ は `u` `n`、∅ は `{}`、`·` は `*`、✓ ✗ は `OK` `NO`、06 の論理式は `!` `&` `|`）。要素の名前は 14 px 以上にしたので（p5.js 版は大きな束で 10〜12 px）、`abcd` のような長い名前は丸から少しはみ出します。07・09 は丸を少し大きくしました。長い説明は単語の区切りで折り返し、いくつかの行は短くしたり別の行に分けたりしています。
- **自己テスト**：p5.js 版と同じ項目を同じ例で照合します（全部で 92 項目）。結果は端末に出し、画面右下にも `Self-test OK 5 / 5` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、引く順番もそろえたので、ランダムな半順序・束は p5.js 版と同じものができます。
- **重い計算**：束の表・N5/M3 の探索・クワイン-マクラスキー法・反鎖の分枝限定法・マッチングなどは、キーやクリックのときに 1 回だけ計算して覚えておきます（描くたびには計算しません）。06 の総当たりは p5.js 版と同じなので、主項がとても多い式ではクリックのときに止まることがあるのも同じです。
- **14 束の音**：Web Audio の代わりに Art.Sound の `playTone` で鳴らします。時間をずらして鳴らす音は World の待ち行列に入れ、時刻が来たものを 1 コマに 6 音まで鳴らすので、タイミングは 1 コマ＋再生の遅れくらいずれます。音は三角波 1 つ（p5.js 版の 2 倍音の正弦波とローパスフィルタはなし）、音量は `master` 0.12 × 0.4 以下。最初のクリックは要らず、キーかクリックで音が始まります。スペースのランダムな鎖は `randomRIO`、自己テストの 30 本の鎖は種つきの乱数（種 14）で選びます（p5.js 版は `Math.random`）。
- **15 カメラ**：カメラは ffmpeg 経由で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像になります（48 ブロックの属性は p5.js 版と同じ）。文脈と概念束は p5.js 版と同じく 6 コマに 1 回計算し直します。`S` の保存は PNG ではなく SVG です。
