# シリーズ19：モルフォロジー（数理モルフォロジー）─ Haskell コード集

画像を「0 と 1 のマス目」として、小さな形（構造要素）で太らせ・やせさせ・削る。膨張・収縮から細線化・距離変換・ウォーターシェッドまで、数理モルフォロジー（Mathematical Morphology）を体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結していて、構造要素の生成、膨張・収縮、ユークリッド距離変換（Felzenszwalb & Huttenlocher の 1 次元ずつの放物線法）も、使うスケッチの一番下の「道具」に入っています。画像の外側は端のマスと同じ値として扱います。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series19/

## 使い方

```sh
cabal run s19-00
```

番号を変えると別のスケッチが動きます（`s19-07`、`s19-12` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。最初に 1 回クリックすると音が出るようになるのは p5.js 版と同じです（13 はスペースでも）。
- 📷 カメラは `ffmpeg` で読みます。使えないときはデモの映像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：英語です。記号は ⊕ を `(+)`、⊖ を `(-)`、∘ を `o`、• を `.`、Aᶜ を `A^c` と書きます。
- **文字のお手本（01・02・03・05・08・10・13）**：gloss には文字を画像に焼く機能がないので、「p5」「ab」「音」の形を太い折れ線で作ってあります（道具の `glyphs`）。形はブラウザのフォントとは少し違います。
- **乱数とノイズ**：乱数の列が違うので、ゴミ・粒・塊の位置は p5.js 版と違います（種を固定すると毎回同じになるのは同じです）。`noise` は 4 オクターブの `fbm2` に置きかえ、`noiseSeed` はノイズを見る場所をずらして代用します。
- **12**：地形 1 は、`fbm2` の振れ幅が小さいので 2 倍に広げてから高さにします。
- **13**：鳴らしっぱなしの音は、1 ステップごとの短い音の連なりになります。発音までに少し遅れがあります。
- **14**：S の保存は PNG ではなく SVG です。発音までに少し遅れがあります。
- **15**：カメラが使えないときはデモの映像で動きます。
