# シリーズ37：離散モース理論 ─ Haskell コード集

山と谷と峠だけで「形」が決まる。なめらかなモース理論（高さ関数の臨界点）から、フォルマンの離散モース理論（胞体複体の上の矢印）へ。勾配ベクトル場・崩壊・モース不等式・パーシステンスによる簡略化を、格子と地形と画像の上で体験する 16 本を、Haskell（gloss）に移植したコード集です。どのスケッチも `Main.hs` 1 ファイルで完結していて、下の方に「離散モース理論の道具」が入っています。勾配場は Robins・Wood・Sheppard（2011）の lower star 法、キャンセルはフォルマンの定理（V-パスがただ 1 本のペアを逆向きに）で実装しています。ベッチ数は Z2 係数で、b0 は Union-Find、b2 は閉じた曲面の数、b1 = b0 + b2 − χ です。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series37/

## 使い方

```sh
cabal run s37-00
```

番号を変えると別のスケッチが動きます（`s37-07`、`s37-14` など）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。
- 📷 カメラは `ffmpeg` で読みます。使えないときは動くノイズ画像で動き、画面にそのことが表示されます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を表示できないので、画面の文字は短い英語です。χ や ε も `chi`、`eps` と書きます。文字が横に長くなるので、説明の行を分けたり短くしたりしています。14 より小さい文字は 14 にそろえました。
- **ノイズ**：p5.js の `noise` / `noiseSeed` の代わりに、ライブラリのパーリンノイズを重ね、座標をずらして新しい地形を作ります。同じ番号でも地形や臨界点の数は p5.js 版と同じにはなりません。
- **Shift+ドラッグ**（09・14）：ドラッグの途中で Shift を調べられないので、押し始めたときの Shift で盛り上げる／掘るを決めます。
- **00**：「臨界点を通過」の文字は、水位の行と重ならないように地形のすぐ上に出します。
- **04・07・08**：V-パスと次に消すペアは毎フレームではなく、矢印が変わったときだけ計算します。04 は 1 つの臨界胞体から描くパスを 400 本までにしています。
- **06**：棒の上は数だけにし、`m0`、`b0` の名前は棒の下に書きます（幅 1280 では重なるため）。履歴は 4 つずつ折り返します。
- **07**：「最適」の文字は、幅に入るように 2 行に分けています。
- **09・11**：稜線と谷線は重なる線分を 1 回だけ描き、1 つの鞍点から描くパスを 200 本までにしています。
- **10・11**：キャンセルの列は、パスをたどった結果を覚えておき、組み替えた胞体にふれるものだけ計算しなおします（列の作り方は同じです）。固まらないように 1 フレーム 8 回ずつ計算し、その間は `computing...` と表示して描きなおしません。
- **12**：WEBGL とテクスチャの代わりに、格子の絵をトーラスの座標にうつして画家のアルゴリズムで描きます。線や点はマスごとの折れ線で近似し、面より少し手前に置くので、テクスチャと完全には同じ見た目になりません。
- **13**：Web Audio の代わりに波形のファイルを再生コマンドで鳴らすので、発音まで少し遅れ、同時に 8 音までです。音量の変化もライブラリの音の形になります。最初のクリックは要りません。
- **14**：S の保存は PNG ではなく SVG です。
- **15**：カメラは 64 × 48 に縮小して読みます。カメラの向きは `startCamera` で左右反転しています。映像は高さの計算と同じ 3 フレームごとに更新します。
