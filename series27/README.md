# シリーズ27：トポロジー ─ Haskell コード集

伸ばしても曲げても変わらない「つながり方」を見る、ゴムの幾何学の 16 本を Haskell（gloss）に移植したコード集です。一筆書きとオイラー標数、メビウスの帯とクラインの壺、曲面の分類、結び目、ループと回転数、毛玉の定理までを、形をさわって確かめます。どのスケッチも `Main.hs` 1 ファイルで完結しています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series27/

## 使い方

```sh
cabal run s27-00
```

番号を変えると別のスケッチが動きます（`s27-07`、`s27-15` など）。

- 🔊 音を使うスケッチ（13・14）は `afplay`（macOS）または `aplay`（Linux）で鳴らします。実行したら、まず画面を 1 回クリックします。
- 📷 カメラ（15）は `ffmpeg` で読みます。使えないときは模様で動きます。

## p5.js 版との違い

- **画面**：画面の配置は 1280 × 800 に合わせて固定です。マウスを動かす前の位置は、画面の左上ではなく中央です。
- **3D（04・05・07・12）**：OpenGL の深度バッファを使わず、面を奥から順に描きます（画家のアルゴリズム）。光は面ごとの計算で、p5.js 版と明るさは同じになりません。自分と交わる曲面（05 のクラインの壺と射影平面）では、交わる線のあたりがギザギザに見えることがあります。
- **00・02**：gloss の多角形は凸形しか正しく塗れないので、へこみのある面は細い横帯を並べて塗ります。枠の角は丸くありません。
- **03・09**：描く線の点は 3000 点までです。
- **07**：チューブの断面は 8 角形で、裏を向いた面は描きません。本数が多い絡み目では、全体が 360 点ほどになるようにチューブの点を間引きます（右の図と交点の数はすべての点で計算します）。つやは 1 つの光だけの簡単な計算です。
- **12**：球は陰影をつけた円を重ねて描き、裏側の毛・粒・赤い玉は描きません。
- **13**：音は `Art.Sound` で鳴らします。連続音ではなく 0.25 秒ごとの短い音の連なりになり、発音まで少し遅れます。左右の定位とローパスフィルタはありません。
- **14**：絵は 256 × 256 マスに覚えて 2.25 倍で表示するので、p5.js 版より少し粗くなります。S は PNG ではなく SVG に保存します。V の周りの 8 枚は半透明ではなく、暗い色を重ねています。描いている間の音は 0.15 秒ごとの短い音で、「チン」の音は同じ長さです。
- **15**：カメラは ffmpeg で読みます（`Art.Device`）。S は SVG に保存します。逆写像は変形を変えたときだけ計算して表にしておき、映像が来るたびに表を引きます。方眼の線は説明文の部分には描きません。
