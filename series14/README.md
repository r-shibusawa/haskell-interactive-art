# シリーズ14：グラフアルゴリズム ─ Haskell コード集

参考：Cormen ほか『Introduction to Algorithms』

幅優先探索・深さ優先探索とその応用、最小全域木、単一始点・全点対の最短経路を、1 手ずつ動くアニメーションと疑似コードで体験する 16 本を、Haskell（gloss）に移植したコード集です。JavaScript のジェネレータの代わりに、do 記法で書けて `yield` で 1 手休む小さなモナド `Algo` を使っています。どのスケッチも `Main.hs` 1 ファイルで完結していて、一番下に共通の「グラフを描く・動かすための道具」が入っています。

p5.js 版： https://r-shibusawa.github.io/p5-interactive-art/series14/

## 使い方

```sh
cabal run s14-00
```

番号を変えると別のスケッチが動きます（`s14-07`、`s14-12` など）。

共通の操作：**スペース＝再生/停止、→＝1 手ずつ、↑↓＝速さ、R＝最初から、S＝画面を保存**。右側の疑似コードで、いま実行している行が光ります（00・07・13 は操作が少し違います。表を見てください）。

- 🔊 音を使うスケッチは `afplay`（macOS）または `aplay`（Linux）で鳴らします。

## p5.js 版との違い

- 画面の文字は英語（ASCII）です。疑似コード、メッセージ、03 と 11 のお手本の点の名前も短い英語にしました（例：米研ぎ → Wash、基礎 → Base）。∞ は `inf`、π は `pi`、⊗ は `(x)`、ŵ は `w^`、δ̂ は `dh` と書きます。
- S の保存は PNG ではなく SVG です。
- 線の角丸や太字はありません。枠の丸い四角は普通の四角になります。
- 13 の音はスケジュール再生ではなく、フレームごとに通り過ぎた音を鳴らすので、少し遅れます。同時に鳴る音は 8 音までです（BFS の和音で音が欠けることがあります）。「まずクリック」は要りません。
- 01・08 は点が右のパネルに重ならないよう、グラフの範囲を 30 ピクセル狭くしました。06 は判定文を少し下げました。15 は 6 点でも表が画面に収まるよう、マスを小さくします。05 と 14 の疑似コードは、英語の長さの都合で行を分けたり短くしたりしています。
- 12 で手で負の閉路を作っても止まらないように、経路をたどる回数に上限を入れています。
