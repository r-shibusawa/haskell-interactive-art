# Haskell でつくるインタラクティブアート

[p5.js 版コード集](https://github.com/r-shibusawa/p5-interactive-art)（[サイト](https://r-shibusawa.github.io/p5-interactive-art/)）の全 43 シリーズ・688 スケッチを、Haskell と [gloss](https://hackage.haskell.org/package/gloss) に移植したコード集です。各スケッチは 1 ファイルの `Main.hs` で、フォルダ名と操作は p5.js 版と揃えています。

## 動かし方

GHC（9.6 以降を推奨、9.10.1 で確認）、cabal、GLUT、そして音やカメラを使うなら下の道具を用意します。

```sh
git clone https://github.com/r-shibusawa/haskell-interactive-art.git
cd haskell-interactive-art
cabal update
cabal run s22-03    # シリーズ 22 のスケッチ 03
```

実行ファイル名は `s<シリーズ番号>-<スケッチ番号2桁>` です（例：`s1-00`）。初回は gloss などのライブラリのビルドに数分かかります。

| 使うもの | 必要なもの | 無いとき |
|---|---|---|
| ウィンドウ（全スケッチ） | macOS は標準の GLUT、Linux は freeglut | 起動できない |
| 🔊 音 | macOS は `afplay`（標準）、Linux は `aplay` | 音なしで動く |
| 🎤 マイク・📷 カメラ | `ffmpeg`（macOS と Linux）。端末にマイクとカメラの許可が必要 | 合成信号やマウス操作に切りかわる |

GHC 9.4.1 の実行ファイルは、新しい macOS のリンカでは起動時に落ちることがありました。そのときは新しい GHC を使ってください。

## p5.js 版との共通の違い

- **画面の文字：** gloss の文字は ASCII だけなので、画面の説明は英語です。コードのコメントと README は日本語です。
- **Esc キー：** gloss では Esc でウィンドウが閉じます。
- **音：** 波形を WAV に書いて再生するので少し遅れます。同時に 8 音までで、連続音は短い音の連なりになります。
- **描き足し：** gloss は毎フレーム描き直すので、軌跡やブラシは履歴やピクセルバッファで表します。古い線が消えたり、粗く見えたりします。
- **3D：** 深度バッファを使わず、奥から順に描きます（画家のアルゴリズム）。面が交わるところは前後が乱れることがあります。
- **保存：** S キーの保存は PNG ではなく SVG です。
- シリーズごとの違いは、各シリーズの README の「p5.js 版との違い」にあります。

## 構成

```
src/Art/        共通ライブラリ（骨組み、描画の道具、音、マイク、カメラ、SVG）
seriesN/        README.md と sketches/NN_slug/Main.hs
tools/          check.sh（ウィンドウを開かないテスト）、snap.sh（画像の確認）、gen-cabal.py
```

テストは次のように実行します。`tools/env.local` にツールのパスを書くこともできます。

```sh
cabal build lib:haskell-interactive-art
tools/check.sh 22    # シリーズ 22 の全スケッチをテストモードで実行
```
