# シリーズ51：サイバネティクス ─ Haskell コード集

「動物と機械における制御と通信」（ウィーナー『サイバネティックス』1948）。結果が原因にもどってくる「円環的な因果」を、本物のシミュレーションで動かして見るコード集です。サーモスタットとワットの調速機の負のフィードバック、遅れが生む企図振戦、予測して狙う射撃から、アシュビーのホメオスタット・必要多様度の法則・ブラックボックス、グレイ・ウォルターの亀とブライテンベルクの乗り物、マカロック-ピッツのニューロン、オートポイエーシス、ビアの存続可能システム、互いを観察する系と固有形まで。最後は音と光の Musicolour とビデオフィードバックで作品に。p5.js 版と同じ計算（4 次のルンゲ＝クッタ法、小さなきざみのオイラー法、最小二乗、同じ種の乱数）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series51/

## 使い方

```
cabal run s51-00
```

番号を変えると別のスケッチが動きます（`s51-01`、`s51-15` など）。どのスケッチも一番下に「サイバネティクスの道具」（グラフ・ブロック図・乱数・自己テスト、RK4・最小二乗など）が入っています。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語を出せないので、説明は短い英語です。記号は ASCII で書きます（τ は `tau`、℃ は `C`、± は `+-`、≤ は `<=`、✓ は `OK`）。長い操作説明は 2 行に分け、そのぶん図やグラフを少し下げています。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差で照合します（全部で 95 項目）。結果は端末に出し、画面左下にも `Self-test OK 7 / 7` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：p5.js 版の `makeRng`（mulberry32）を 32 ビットの整数でそのまま書き直したので、種を決めた計算（自己テストなど）は p5.js 版と同じ乱数列になります。
- **線と点線**：gloss の線は細いので、グラフの太い線・ブロック図の枠は細い多角形で描きます。点線は自分で区切って描きます。角の丸い箱は普通の長方形です。
- **04 ホメオスタット**：種 3 は p5.js 版と同じく 62 回の取りかえ（約 59 秒）で安定します。重みの表のマスは数字が読めるように 46 px から 62 px に広げました（クリックの範囲も同じ）。
- **05 必要多様度・09 マカロック-ピッツ**：自動で進む間隔はフレームの経過時間 dt で数えます（60 fps なら p5.js 版と同じ）。
- **07 亀・08 ブライテンベルク**：ふるまい・性格の名前は英語（searching / dazzled: away / low battery: home …、2a fear / 2b aggression / 3a love / 3b explorer）です。楕円は円を伸ばして、07 の目の視野（扇形）は多角形で描きます。08 の V（乗り物を足す）は p5.js 版と同じく種なしの乱数です。
- **10 オートポイエーシス**：格子は unboxed 配列で書きかえます。右に英語の説明を入れるため、格子は画面の幅の 60%（p5.js 版は 66%）です。
- **13 固有形**：3 の点の集まり（最大 139968 点）は、8 万画素以下のピクセル画像に 1 画素の点で塗り、点が変わったときだけ作りなおします（p5.js 版は 5000 点以下を太さ 3 の点で）。変化 d の記録は新しい方から 1500 個までです。
- **14 Musicolour**：Web Audio の代わりに Art.Sound の `playTone` で 1 音ずつ鳴らします（ブラウザの圧縮器はありません）。最初のクリックは要らず、キーを押すとすぐ鳴ります。
- **15 ビデオフィードバック**：カメラは ffmpeg 経由で 200×150 で読みます。カメラが無いか V で切ると、p5.js 版と同じ動く丸と帯のテスト画像を使います。`S` の保存は PNG ではなく SVG です。
