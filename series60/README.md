# シリーズ60：主成分分析 ─ Haskell コード集

たくさんの数をもつデータを「いちばんばらつく向き」から見る ― 主成分分析（PCA）を**計算の道具として**使うコード集です。平均・分散・共分散から始めて、射影した分散が最大の向き、共分散行列と固有ベクトル、3 次元の点群（ヤコビ法）、べき乗法とデフレーション、特異値分解、寄与率とスクリープロット、復元と誤差、固有顔、自分で描いた文字の主成分、標準化と白色化、カーネル PCA、独立成分分析（FastICA）、外れ値、音色マップ、カメラ映像の色まで、どれも機械学習のライブラリを使わずに**本当に計算した**シミュレーションです。データはすべて種つきの乱数で作った合成データ（実在のデータセットではありません）。p5.js 版と同じ計算（共分散行列、ヤコビ法、べき乗法とデフレーション、XᵀX の固有値分解による特異値分解、部分空間反復法とグラム行列、白色化、RBF カーネルと特徴空間での中心化、FastICA、中央値と重みつき共分散）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series60/

## 使い方

```
cabal run s60-00
```

番号を変えると別のスケッチが動きます（`s60-01`、`s60-15` など）。どのスケッチも一番下に「主成分分析の道具」（共分散行列、ヤコビ法、部分空間反復法、白色化、カーネル、FastICA、種つき乱数、自己テストなど）が入っています。約束：データ X は「n 行 × d 列」（1 行 = 1 個のデータ）。共分散は n − 1 で割る（C = Xcᵀ Xc / (n − 1)）。復元誤差も同じく Σ‖x − x_hat‖² / (n − 1) で、これが捨てた固有値の和になります。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や数学記号を出せないので、説明は短い英語で、記号は ASCII で書きます（λ は `lambda` または `l`、σ は `s`、μ は `mu`、Σ は `sum`、ᵀ は `^T`、✓ は `OK`）。12〜13 px の小さい文字は 14 px にしました。
- **行列の持ち方**：ベクトルは unboxed の `Double` の並び（`Vec`）、行列とデータはその行の並び（`Mat`）です。ヤコビ法・共分散行列は破壊的に書きかえる配列（ST モナド）で計算しますが、足し算の順番は p5.js 版と同じです。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、引く順番もそろえた（乱数を順に引く小さなモナド `R`）ので、点群・顔・文字・信号と、そこから求めた固有値は p5.js 版と同じです（Node.js で動かした p5.js 版の道具と、最後の桁のちがいまで照合しました）。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 101 項目）。結果は起動時に端末に出し、画面右下にも `Self-test OK 8 / 8` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **重い作り直し（07・08・11）**：p5.js 版がキーを押したときにその場で計算し直す部分（07 の 64 次元のヤコビ法と復元誤差、08 の顔 200 枚とグラム行列の部分空間反復法、11 の 200×200 のカーネル行列）は、画面を止めないように別のスレッドで計算し、できあがるまで前の結果と `computing...` を表示します。計算の中身と結果は同じです。起動時の計算はその場で行います。
- **画素の絵**：07 の模様、08 の顔・固有顔、09 の 16×16 の文字、11 の背景は、マスごとの四角形ではなく画素の絵（`pixelImage`）として作り直したときだけ作ります。
- **03 3 次元の点群**：WEBGL と orbitControl の代わりに、`V3` の回転と透視投影、奥から順に描く（`depthSort`）自前のカメラで描きます。ドラッグで回し、点は小さな立方体ではなく小さな円です。
- **14 音色の主成分**：Web Audio で 12 本の倍音を鳴らし続ける代わりに、Art.Sound の `playTone`（同時に 8 音まで）で、強い倍音 5 つを 0.25 秒ごとに短い音として鳴らしなおします（全体の音量 0.1）。
- **15 カメラ**：カメラは Art.Device（ffmpeg 経由、160×120、左右反転）で読みます。カメラが無いか V で切ると、p5.js 版と同じテスト画像になります。画素の色は unboxed の数の並びのまま共分散を計算します。`S` の保存は PNG ではなく SVG です。
