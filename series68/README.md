# シリーズ68：神経回路網理論 ─ Haskell コード集

**ニューロンをつないだ網が「なぜ」学習できるのか** を理論で見る ― 神経回路網理論のコード集です。1 個のニューロン（パーセプトロンと収束定理、活性化関数、カバーの定理と線形分離の容量、万能近似）から始めて、学習のしくみ（計算グラフと誤差逆伝播、XOR を解く隠れ層、損失の地形、深さと初期化）、汎化（二重降下、正則化、畳み込みと等変性、再帰網の力学とリザバー計算）、連想記憶とエネルギー（ホップフィールド網、ボルツマンマシン）、そしてスパイクするニューロンの音とカメラ映像を学ぶパーセプトロンまで、どれも**ライブラリを使わずにゼロから実装して、定理や公式と答えが一致することを確かめる**スケッチです。p5.js 版と同じ計算（ノビコフの収束定理つきのパーセプトロン、総当たりの線形分離判定とカバーの関数計数定理、シグモイドの段・ReLU の折れ線による構成的な万能近似、スカラーの計算グラフと誤差逆伝播、2-2-1 のネットの XOR、損失の断面と主成分（べき乗法）、分散の漸化式（数値積分）とランダムなネット、ランダム特徴の最小ノルム解とリッジ回帰、重み減衰・早期終了・ドロップアウトと Adam、循環境界の畳み込み、エコーステートネットワークとスペクトル半径、整数のヘッブ則のホップフィールド網、分配関数を数え上げる制限ボルツマンマシンと CD-1、漏れ積分発火ニューロンの正確な指数の積分）を Haskell（gloss）で書き直し、計算は倍精度（`Double`）で行っています。乱数は p5.js 版と同じ種つきの mulberry32 で、引く順番もそろえてあるので、データ・学習の結果・自己テストの数値は p5.js 版と同じになります。

p5.js 版：https://r-shibusawa.github.io/p5-interactive-art/series68/

## 使い方

```
cabal run s68-00
```

番号を変えると別のスケッチが動きます（`s68-01`、`s68-15` など）。どのスケッチも一番下に「神経回路網の道具」（種つきの乱数、行列の道具とリッジ回帰、活性化関数、小さなニューラルネット、画像とグラフを描く道具、自己テストなど）が入っています。学習やシミュレーションは 1 フレームに少しずつ進めるので、画面は止まりません。右下の `Self-test OK n / n` が計算の正しさの目印です。記号は画面では ASCII で書きます（σ → `sigma` または `sig`、γ → `gamma`、λ → `lambda`、ρ → `rho`、θ → `theta`、τ → `tau`、‖w‖ → `|w|`、√ → `sqrt`、² → `^2`、∂L/∂w → `dL/dw`、≤ → `<=`、≈ → `~`、①②③ → `(1)(2)(3)`）。色：+1・クラス 1 = マゼンタ、−1・クラス 0 = ライム。🔊 音を使うスケッチ（14）は Art.Sound で鳴らします。**音量は小さめから**（全体の音量 `master` は 0.2 以下）。📷 カメラ（15）はカメラがなくてもテスト画像で動きます。

## p5.js 版との違い

- **画面の文字**：gloss のフォントは日本語や数学記号を出せないので、説明は短い英語で、記号は ASCII で書きます（上の「使い方」の対応）。グラフの目盛り・凡例の 11〜13 px の文字は 14 px にし、はみ出さないように説明を短くしたり 2 行に分けたりしています。関数の名前（ステップ・シグモイドなど）や 12 の絵の名前（ハート・家など）も英語です。角の丸い四角形は、ふつうの四角形で描きます。
- **自己テスト**：p5.js 版と同じ項目・同じ許容誤差・同じ種で照合します（全部で 86 項目）。項目の名前と中に入る数値も p5.js 版と同じです（例：00 の k = 9 ≤ 375、05 の種 2 が 394 歩、08 の山 p = 10、12 の重なり 0.58、14 の 33 → 57 回/秒）。結果は端末に出し、画面右下にも `Self-test OK 5 / 5` のように合格数を表示します（テストモードでは失敗した項目とまとめの 1 行だけを出します）。
- **乱数**：p5.js 版の `rnd()`（mulberry32）を 32 ビットの整数でそのまま書き直し、乱数の列を 1 本だけ持って引く順番もそろえた（乱数を順に引く小さなモナド `R`）ので、データ・初期値・学習の結果は p5.js 版と同じです。mulberry32 は状態に毎回同じ数を足すだけなので、たくさんの乱数（07 の重み行列など）は `rndVec`・`randnVec` で番号から直接まとめて作ります（引く順番と値は 1 つずつ引くのと同じ）。p5.js 版で描画中も同じ列から引き続ける所（09 のドロップアウト、12 の更新、13 の CD-1 と夢）は、乱数の状態を `World` に入れて続けます。
- **画像の作り直し**：p5.js 版がオフスクリーンの画像に描いて使い回す所（05・06・09 の境界や等高線など）は、同じタイミングで作った `Picture` を `World` に入れて使い回します。
- **1 フレームの計算**：p5.js 版が `performance.now()` の時間で区切る計算は、1 フレームに決まった量だけ進めます（06 の等高線の格子は 12 行ずつ、08 の平均は 1 組ずつ（40 フレームで 40 組）、12 の容量の実験は 1 点ずつ）。乱数を引く順番は同じです。
- **自己テストの小さな残りの表示**：差分や 10⁻¹³ より小さい残りを表示する項目は、JavaScript とシステムの数学ライブラリ（log・tanh・sin など）の最後の 1 けたのちがいで、表示される値が p5.js 版と少しちがうことがあります（05 の相対誤差 4.6e-9 ⇔ 1.9e-9、06 のずれ 1.1e-18 ⇔ 4.8e-18、11 の距離 5.2e-16 ⇔ 5.0e-16 と残り 2.1e-13 ⇔ 2.6e-13、14 の発火時刻のずれ 3.5e-17 ⇔ 3.1e-17）。合否と、ほかの数（歩数、損失、種の成否など）は同じです。
- **04 計算グラフ**：ノードの箱の中は `v`（前向きの値）と `g`（勾配）の 2 行で書きます。矢印の局所的な微分は `x0.524` のように書きます。
- **05 XOR**：2 枚の色の絵（入力の空間・隠れ層の空間）は p5.js 版と同じく 4 フレームに 1 回描き直します。種 1〜40 の成否（`surveySeeds 40 3000`）は起動時に計算します（18 / 40、p5.js 版と同じ）。
- **06 損失の地形**：等高線の絵はできあがったときに 1 回だけ作ります。3D は p5.js 版と同じく、自分で射影したワイヤーフレーム（← → とスペースで回す）です。
- **07 深さと初期化**：p5.js 版は 1 フレームに 1 個のネットを作りますが、ここでは 1 個を 41 個の仕事（前向き 20 層・出力側の勾配・後ろ向き 20 層）に分けて、1 フレームに 21 個ずつ進めます（約 2 フレームで 1 個、`unitsPerFrame`）。平均が理論に近づく速さは半分になります。乱数を引く順番は同じですが、計算の途中でキーを押してやり直すと、作りかけのネットは捨てます。
- **08 二重降下**：最小ノルム解（λ = 1e-10）はとても解きにくい連立方程式なので、平均のテスト誤差が p5.js 版と 1 億分の 1 くらいずれることがあります（数学関数の最後の桁のちがいが大きくなるため）。リッジの曲線と自己テストの値は同じです。特徴の折れ目は「|」の文字ではなく短い線で描きます。
- **10・12 Shift**：Shift で消す・黒を描くのは、マウスを押したときの修飾キー、または押している左右の Shift キーで判断します。
- **11 リザバー**：網の作り直し（キーを押したとき）は、押したフレームで網を作り、続く 3 フレームで「状態」「出力の重み（リッジ回帰）」「ρ の測り直し」を計算します（その間、NMSE は `...`）。網はまばらな行列（0 でない所だけ）で持ちますが、0 を足しても和は変わらないので答えは同じです。
- **12 ホップフィールド網**：絵の名前は英語（Heart / House / Face / Cross / Moon / Stripes）で、重なり m は名前の下の行に出します。
- **14 スパイクするニューロンの音**：Web Audio の代わりに Art.Sound の `playTone` を使います（三角波 0.25 秒、音量 0.35 × `master` = 0.035、1 フレームに 4 音まで）。p5.js 版と同じく、クリックかキーを押すまでは鳴りません。しきい値の点線は短い線分を並べて描きます。
- **15 カメラ**：カメラは Art.Device（ffmpeg 経由、64 × 48、左右反転）で読み、明るさは 0.3 R + 0.59 G + 0.11 B です。カメラがないときや C で切ったときは、p5.js 版と同じテスト画像（マウスの高さ = 手の高さ）を使います。教えた例の小さな絵は、例を加えたときに 1 回だけ作ります。`S` の保存は PNG ではなく SVG です。
